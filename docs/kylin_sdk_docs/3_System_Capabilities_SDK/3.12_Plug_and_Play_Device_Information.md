# 3.12 即插即用设备信息

本层主要提供即插即用设备信息获取和监控设备连接/断开信号
安装命令

```bash
$ sudo apt-get install libkysdk-pnp libkysdk-pnp-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-pnp
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-pnp)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 3.12.1 即插即用设备信息

头文件路径
` #include "kysdk/kysdk-system/libkypnp.h"`
so库路径

```
/usr/lib/*/libkypnp.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
```c
// 回调函数原型
typedef void (*KdkPnpCallback)(char *action, char *sys_path);
typedef struct _kdk_pnp_info
{
```
char *sysname;              // 设备名称
char *sysnum;               // 设备数字标识符
char *id;                   // 设备的ID信息。
char *status;               // 设备的当前状态。
char *mem;                  // 设备内存资源（起始地址-结束地址）
char *hid;                  // 设备的HID。
char *control;              // 设备的电源状态
```c
    struct _kdk_pnp_info *next; // 指针
} kdk_pnp_info;
```

> 📌 获取系统中pnp设备信息(自3.0.1.0版本启用)
> **子模块**: 即插即用模块 | **接口类型**: C

**原型**:
```c
kdk_pnp_info* kdk_pnp_get_info();
```

**描述**: 获取系统中pnp设备信息

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `kdk_pnp_info *` | pnp设备信息结构体列表 |


**备注**: 无
