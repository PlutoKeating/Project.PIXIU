# 3.15.2 日历

头文件路径
` #include "kysdk/kysdk-system/libkycalendar.h"`
so库路径

```
/usr/lib/*/libkycalendar.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息

> 📌 打开日历(自3.0.1.0版本启用)
> **子模块**: 应用能力 | **接口类型**: C

**原型**:
```c

```

**描述**: 打开日历

**参数**:

| 参数 | 说明 |
|------|------|
| `day` | 日 |
| `month` | 月 |
| `year` | 年 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `1` | - |
| `成功` | - |
| `-1` | 失败 |
