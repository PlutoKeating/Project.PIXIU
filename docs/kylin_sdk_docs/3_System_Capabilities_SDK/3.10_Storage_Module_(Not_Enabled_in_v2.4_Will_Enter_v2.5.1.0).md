# 3.10 存储模块(2.4版本未启用，将进入2.5.1.0版本)

获取存储模块信息
安装命令

```bash
$ sudo apt install libkysdk-storage libkysdk-storage-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-systime
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDKSYSTIME kysdk-storage)
target_include_directories(demo PRIVATE ${KYSDKSYSTIME_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDKSYSTIME_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDKSYSTIME_LIBRARIES})

#### 3.10.1 获取存储信息

头文件路径
#include /usr/include/kysdk/kysdk-system/libkystorage.h
so库路径

```
/usr/lib/*/libkystorage.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
```c
typedef struct _FileInfo
{
    char name[256];
    int is_dir;
    struct _FileInfo *next;
}FileInfo;
```

> 📌 获取默认浏览器 Cookie 的路径(自2.5.1.0版本启用)
> **子模块**: 存储模块 | **接口类型**: C

**原型**:
```c
char *kdk_storage_get_default_cookie_path()
```

**描述**: 获取默认浏览器 Cookie 的路径

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char *` | 浏览器 Cookie 的路径 |


**备注**: 返回值需要释放
目前仅支持qax，chrome，chromium和firefox,默认浏览器不是这四款会返回NULL

> 📌 压缩数据(自3.0.1.0版本启用)
> **子模块**: 获取存储信息 | **接口类型**: C

**原型**:
```c
int kdk_storage_data_compress(IN kdk_compress_algorithm algorithm, IN char *iData, IN
int iSize, OUT char *oData, IN OUT int *oSize);
```

**描述**: 压缩数据

**参数**:

| 参数 | 说明 |
|------|------|
| `algorithm` | 压缩算法 |
| `iData` | 待压缩数据 |
| `iSize` | 待压缩数据大小 |
| `oData` | 压缩后数据 |
| `oSize` | 输入时表示oData的缓冲区大小，输出时表示压缩后数据大小 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | - |
| `-1` | 失败 |
| `-2` | 不支持的压缩算法 |


**备注**: typedef enum _kdk_compress_algorithm
{
COMPRESS_ALGORITHM_ZIP, // zip压缩
COMPRESS_ALGORITHM_GZIP, // gzip压缩
COMPRESS_ALGORITHM_BZIP2, // bzip2压缩
COMPRESS_ALGORITHM_X, // xz压缩
COMPRESS_ALGORITHM_LZ4, // lz4压缩
COMPRESS_ALGORITHM_ZSTD, // zstd压缩
COMPRESS_ALGORITHM_7Z // 7z压缩
} kdk_compress_algorithm;
