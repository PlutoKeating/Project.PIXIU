# 3.14 系统关闭

提供关机、定时关机、倒计时关机、取消关机等系统关闭操作
安装命令

```bash
$ sudo apt-get install libkysdk-shutdown libkysdk-shutdown-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-shutdown
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-shutdown)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 3.14.1 系统关闭

头文件路径
` #include "kysdk/kysdk-system/libkyshutdown.h"`
so库路径

```
/usr/lib/*/libkyshutdown.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
```c
typedef struct _kdk_timeinfo{
    char *time;   // 时间
    char *timesec;  // 带秒钟数时间
}kdk_timeinfo;
```

> 📌 设置指定时间后关闭当前系统(自3.0.1.0版本启用)
> **子模块**: 系统关闭 | **接口类型**: C

**原型**:
```c
int kdk_shutdown_power_off(int min);
```

**描述**: 设置指定时间后关闭当前系统

**参数**:

| 参数 | 说明 |
|------|------|
| `min` | 经过多少分钟关机 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | - |
| `-1` | 失败 |


**备注**: 入参为负数立刻关机

---
