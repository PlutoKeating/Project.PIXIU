# 3.15.1 音频播放器

头文件路径
` #include "kysdk/kysdk-system/libkyaudio.h"`
so库路径

```
/usr/lib/*/libkyaudio.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息

> 📌 打开音频播放器(自3.0.1.0版本启用)
> **子模块**: 应用能力 | **接口类型**: C

**原型**:
```c
extern int open_audio();
```

**描述**: 打开音频播放器

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `1` | - |
| `成功` | - |
| `-1` | 失败 |


**备注**: 无
