# 3.8 系统设置

该层主要提供系统设置接口。
安装命令

```bash
$ sudo apt-get install libkysdk-accounts libkysdk-accounts-dev
```

构建示例
（1）.pro 文件构建项目
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-accounts
（2）CMakeLists.txt 构建项目
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDKACCOUNTS kysdk-accounts)
target_include_directories(demo PRIVATE ${KYSDKACCOUNTS_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDKACCOUNTS_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDKACCOUNTS_LIBRARIES})

#### 3.8.1 系统设置功能

头文件路径
`#include "kysdk/kysdk-system/libkyaccounts.h"`
so库路径
/usr/bin/*/libkysdk-accounts.so
'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息

> 📌 创建用户，并创建家目录(自2.4.1.0版本启用)
> **子模块**: 系统设置 | **接口类型**: C

**原型**:
```c
char* kdk_system_create_user(char* name, char* fullName, int accountType)
```

**描述**: 创建用户，并创建家目录

**参数**:

| 参数 | 说明 |
|------|------|
| `name` | 用户名 |
| `fullName` | 用户全名 |
| `accountType` | 创建的类型 |
| `0 标准用户` | 1 管理员用户 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char*` | 成功返回用户家目录路径，失败返回NULL |


**备注**: 返回的字符串需要被 free 释放

| `bool` | 是否成功 |

> 📌 传入调用进程名称，完成调用进程的授权设置(自2.5.1.0版本启用)
> **子模块**: 系统设置 | **接口类型**: C

**原型**:
```c
extern int kdk_login_set_process_name(char *processName);
```

**描述**: 传入调用进程名称，完成调用进程的授权设置；调用该接口需要root权限

**参数**:

| 参数 | 说明 |
|------|------|
| `processName` | 调用进程绝对路径名称 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 唯一id，id大于0时代表设置成功，且需要保存下来，用于后面的 kdk_login_set_auth_token接口，id为-1代表后端程序异常，id为-2时代表权限 不足，id为-3时代表其他错误 |


**备注**: 无
