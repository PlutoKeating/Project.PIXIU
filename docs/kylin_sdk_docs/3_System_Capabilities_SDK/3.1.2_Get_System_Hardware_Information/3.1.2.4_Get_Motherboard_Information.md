# 3.1.2.4 获取主板信息

封装 C 接口获取到主板硬件信息。

**头文件路径：**

` #include "kysdk/kysdk-system/libkyboardinfo.h"`

**so库路径：**


```
/usr/lib/aarch64-linux-gnu/libkyhw.so
```


**子模块信息：**


> 📌 获取主板产品名称信息(自2.0.0.0版本启用)
> **子模块**: 获取主板信息 | **接口类型**: C

**原型**:
```c
extern const char *kdk_board_get_name();
```

**描述**: 获取主板型号

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char*` | 成功返回主板型号，返回的字符串需要被 free 释放 |
| `NULL` | 获取失败 |


**备注**: 无

---


> 📌 获取主板生产日期(自2.0.0.0版本启用)
> **子模块**: 获取主板信息 | **接口类型**: C

**返回值**:
