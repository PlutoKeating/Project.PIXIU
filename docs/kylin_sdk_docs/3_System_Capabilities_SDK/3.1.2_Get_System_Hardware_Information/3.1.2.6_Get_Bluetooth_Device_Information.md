# 3.1.2.6 获取蓝牙设备信息

封装 C 接口获取到蓝牙设备硬件信息。

**头文件路径：**

` #include "kysdk/kysdk-system/libkybluetooth.h"`

**so库路径：**


```
/usr/lib/aarch64-linux-gnu/libkybluetooth.so
```


**子模块信息：**


> 📌 获取蓝牙的设备id(自2.2.3.5版本启用)
> **子模块**: 获取蓝牙设备信息 | **接口类型**: C

**原型**:
```c
extern int** kdk_bluetooth_get_device_id();
```

**描述**: 获取蓝牙的设备id

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int **` | 蓝牙的设备id |
| `0` | 获取失败 |


---


> 📌 获取蓝牙的制造商(自2.2.3.5版本启用)
> **子模块**: 获取蓝牙设备信息 | **接口类型**: C

**原型**:
```c

```

**描述**: 获取蓝牙的制造商

**参数**:

| 参数 | 说明 |
|------|------|
| `num` | 蓝牙设备的个数，从0开始，0代表1个，以此类推 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char*` | 成功返回蓝牙的制造商，返回的字符串需要被 free 释放。 |
| `NULL` | 获取失败 |
