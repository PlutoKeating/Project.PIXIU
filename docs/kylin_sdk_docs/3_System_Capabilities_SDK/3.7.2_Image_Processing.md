# 3.7.2 图像处理

头文件路径
`#include "kysdk/kysdk-system/libkyimageproc.h"`
so库路径

```
/usr/lib/*/libkyimageproc.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息

> 📌 创建图片(自2.5.1.0版本启用)
> **子模块**: 图像处理 | **接口类型**: C

**原型**:
```c
extern void* kdk_image_create_pixelmap(kdk_image_init init);
```

**描述**: 创建图片

**参数**:

| 参数 | 说明 |
|------|------|
| `init` | 创建图片的属性，包括透明度，尺寸，缩略值，像素格式 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `void*` | 图片句柄，失败句柄为空 |


**备注**: typedef enum _AlphaType
{
UNKNOWN, //未知透明度
OPAQUE, //没有alpha或图片全透明
PREMUL, //RGB前乘alpha
UNPREMUL //RGB不前乘alpha
}AlphaType;
typedef enum _PixelMapFormat
{
UNKNOWN_PIXEL, //未知格式
RGB_565 = 2, //格式为RGB_565
RGBA_8888, //格式为RGBA_8888
RGB_888 = 5, //格式为RGB_888
ALPHA_8, //格式为ALPHA_8
RGBA_F169, //格式为RGBA_F16
NV21 //格式为NV21
}PixelMapFormat;
struct Size
{
int height; //输出图片的高
int width; //输出图片的宽
};
typedef struct _kdk_image_init
{
AlphaType alphaType; //透明度
PixelMapFormat pixelFormat; //像素格式
struct Size size; //创建图片大小
}kdk_image_init;
