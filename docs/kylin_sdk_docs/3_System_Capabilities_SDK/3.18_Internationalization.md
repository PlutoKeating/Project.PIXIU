# 3.18 国际化

提供系统语言支持，当前系统语言，当前系统语言与系统地区是否匹配，系统时间与UTC时差等功能
安装命令

```bash
$ sudo apt-get install libkysdk-global libkysdk-global-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-global
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-global)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 3.18.1 国际化

头文件路径
` #include "kysdk/kysdk-system/libkyglobal.h"`
so库路径

```
/usr/lib/*/libkyglobal.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息

> 📌 获取系统支持的语言列表(自3.0.1.0版本启用)
> **子模块**: 国际化 | **接口类型**: C

**原型**:
```c
extern char** kdk_global_get_system_support_language();
```

**描述**: 获取系统支持的语言列表

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char**` | 返回语言列表 |
| `NULL` | 获取失败 |


**备注**: 返回的字符串数组需使用 kdk_free_langlist 释放

---


> 📌 判断当前语言和地区是否匹配(自3.0.1.0版本启用)
> **子模块**: 国际化 | **接口类型**: C

**原型**:
```c
extern bool kdk_global_get_region_match_language();
```

**描述**: 判断当前语言和地区是否匹配

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 匹配 false 不匹配 |


**备注**: 无

---


> 📌 获取系统是否为 从右至左显示语言(自3.0.1.0版本启用)
> **子模块**: 国际化 | **接口类型**: C

**原型**:
```c
extern bool kdk_global_get_rtl();
```

**描述**: 获取系统是否为从右至左显示语言

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 是 false 否 |


**备注**: 无

---


> 📌 获取系统默认时区与UTC时区的偏差(自3.0.1.0版本启用)
> **子模块**: 国际化 | **接口类型**: C

**原型**:
```c
extern int kdk_global_get_raw_offset();
```

**描述**: 获取系统默认时区与 UTC 的偏差

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 偏差的小时数；例如：东八区 = 8；西二区 = -2 |


**备注**: 无

---


> 📌 获取系统语言(自3.0.1.0版本启用)
> **子模块**: 国际化 | **接口类型**: C

**原型**:
```c
extern char* kdk_global_get_system_language(const char *username);
```

**描述**: 获取系统语言

**参数**:

| 参数 | 说明 |
|------|------|
| `username` | 用户名 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char*` | 返回系统语言：中文:"zh_CN"；英文:"en_CN"；藏文:"bo_CN"；返回的字符串需 要被 free 释放 |
| `NULL` | 获取失败 |


**备注**: 语言值示例："zh_CN"、"en_CN"、"bo_CN"

---


> 📌 释放由kdk_global_get_system_support_language返回的系统支持的语言列表(自3.0.1.0版本启用)
> **子模块**: 国际化 | **接口类型**: C

**原型**:
```c
extern void kdk_free_langlist(char** langlist);
```

**描述**: 释放由 kdk_global_get_system_support_language 返回的语言列表

**参数**:

| 参数 | 说明 |
|------|------|
| `langlist` | 语言列表指针 |


**返回值**: 无

**备注**: 无
