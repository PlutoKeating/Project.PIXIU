# 3.17 数据交换

提供获取剪贴板数据，清空剪贴板，注册剪贴板回调函数接口，支持x，wayland和wlcom
安装命令

```bash
$ sudo apt-get install libkysdk-exchange libkysdk-exchange-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-exchange
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-exchange)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 3.17.1 数据交换

头文件路径
` #include "kysdk/kysdk-system/libkydataexchange.h"`
so库路径

```
/usr/lib/*/libkydataexchange.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
/**
```c
 * @brief 剪贴板数据类型枚举
 */
```
```c
typedef enum {
    CLIPBOARD_TYPE_TEXT = 1,  /**< 文本类型数据 */
    CLIPBOARD_TYPE_IMAGE = 2  /**< 图像类型数据 */
} ClipboardDataType;
/**
 * @brief 剪贴板操作结果枚举
 */
typedef enum {
    CLIPBOARD_OPERATION_SUCCESS = 0,              /**< 操作成功 */
    CLIPBOARD_OPERATION_FAILURE = -1,             /**< 操作失败 */
    CLIPBOARD_OPERATION_UNSUPPORTED_TYPE = -2     /**< 不支持的数据类型 */
} ClipboardOperationResult;
/**
 * @brief 剪贴板图像数据结构
 */
typedef struct {
    unsigned char* data;          /**< 图像数据指针 */
    size_t width;                 /**< 图像宽度 */
    size_t height;                /**< 图像高度 */
    size_t bytes_per_pixel;       /**< 每个像素的字节数 */
} ClipboardImage;
/**
 * @brief 剪贴板变化回调函数类型
 * @param user_data 用户自定义数据指针
 */
typedef void (*ClipboardChangeCallback)(void* user_data);
```
