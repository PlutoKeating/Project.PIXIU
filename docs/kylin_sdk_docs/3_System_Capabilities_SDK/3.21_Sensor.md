# 3.21 传感器

提供传感器信息获取等相关接口
安装命令

```bash
$ sudo apt-get install libkysdk-sensors libkysdk-sensors-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-sensors
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-sensors)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

> 📌 获取系统连接的所有传感器芯片名称(自3.0.1.0版本启用)
> **子模块**: 传感器 | **接口类型**: C

**原型**:
```c
extern char** kdk_sensor_get_name();
```

**描述**: 获取系统连接的所有传感器芯片名称

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char**` | 返回传感器芯片名称的字符串数组指针 |
| `NULL` | - |
| `表示失败` | - |


**备注**: 需要调用kdk_free_name释放内存

---


> 📌 释放由kdk_sensor_get_name返回的传感器名称列表(自3.0.1.0版本启用)
> **子模块**: 传感器 | **接口类型**: C

**原型**:
```c
extern void kdk_free_name(char** name);
```

**描述**: 释放由 kdk_sensor_get_name 返回的传感器名称列表

**参数**:
