# 3.13 统一资源标识

处理 URL 和 URI 的创建、解析和验证，包括生成、组合和解析 URI 信息，以便开发者能够高效地管理网络资
源和路径。提供从指定url下载数据的能力
安装命令

```bash
$ sudo apt-get install libkysdk-uri libkysdk-uri-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-uri
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-uri)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

> 📌 检查url字符串是否合法(自3.0.1.0版本启用)
> **子模块**: 统一资源标识 | **接口类型**: C

**原型**:
```c
int kdk_uri_check_is_url(char *url);
```

**描述**: 检查 URL 字符串是否合法

**参数**:

| 参数 | 说明 |
|------|------|
| `url` | URL 字符串 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | 合法 |
| `-1` | - |
| `不合法` | - |


**备注**: 无
