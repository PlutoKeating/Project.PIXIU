# 3.19 音频设备管理

提供支持音频设备列表查询，设备状态查询，音频播放控制，音频处理等功能
安装命令

```bash
$ sudo apt-get install libkysdk-media libkysdk-media-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-media
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-media)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 3.19.1 音频设备管理

头文件路径
` #include "kysdk/kysdk-system/libkymedia.h"`
so库路径

```
/usr/lib/*/libkymedia.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
/* 设备信息结构体 */
```c
typedef struct {
    char name[256];           /* 设备名称 */
    char id[64];              /* 设备ID */
    char longname[256];       /* 设备长名称 */
    int subdevice;           /* 子设备编号 */
    int subdevices_count;    /* 子设备总数 */
    char subdevice_name[64]; /* 子设备名称 */
} kdk_device_info_t;
/* 声卡信息结构体 */
typedef struct {
    int card;                /* 声卡编号 */
    char name[256];          /* 声卡名称 */
    char longname[256];      /* 声卡长名称 */
    kdk_device_info_t* devices; /* 设备列表 */
    int device_count;        /* 设备数量 */
} kdk_sound_card_t;
/* 设备列表结构体 */
typedef struct {
    kdk_device_info_t* devices; /* 设备列表 */
    int count;                  /* 设备数量 */
} kdk_device_list_t;
```

> 📌 获取默认输入设备(自3.0.1.0版本启用)
> **子模块**: 音频设备管理 | **接口类型**: C

**原型**:
```c
kdk_device_info_t* kdk_media_get_default_input_device(void);
```

**描述**: 获取默认输入设备

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `kdk_device_info_t*` | 默认输入设备信息 |
| `NULL` | 获取失败 |


**备注**: 无
