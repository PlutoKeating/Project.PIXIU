# 3.20 系统重启

提供重启功能等相关接口
安装命令

```bash
$ sudo apt-get install libkysdk-restart libkysdk-restart-dev
```

构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-restart
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-restart)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 3.20.1 系统重启

头文件路径
` #include "kysdk/kysdk-system/libkyrestart.h"`
so库路径

```
/usr/lib/*/libkyrestart.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
```c
typedef struct _kdk_timeinfo{
    char *time;   // 时间
    char *timesec;  // 带秒钟数时间
}kdk_timeinfo;
```

> 📌 设置指定时间后重启当前系统(自3.0.1.0版本启用)
> **子模块**: 系统重启 | **接口类型**: C

**原型**:
```c
extern int kdk_restart_reboot(int min);
```

**描述**: 设置指定时间后重启当前系统

**参数**:

| 参数 | 说明 |
|------|------|
| `min` | 经过多少分钟后重启 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | - |
| `-1` | 失败 |


**备注**: 入参为负数立刻重启

---


> 📌 设置在指定时间重启当前系统(自3.0.1.0版本启用)
> **子模块**: 系统重启 | **接口类型**: C

**原型**:
```c
extern int kdk_restart_schedule_reboot(kdk_timeinfo *time);
```

**描述**: 设置在指定时间重启当前系统

**参数**:

| 参数 | 说明 |
|------|------|
| `time` | 指定的重启时间 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | - |
| `-1` | 失败 |


**备注**: 无

---


> 📌 取消当前系统上所有的重启任务(自3.0.1.0版本启用)
> **子模块**: 系统重启 | **接口类型**: C

**原型**:
```c
extern bool kdk_restart_cancel_reboot();
```

**描述**: 取消当前系统上所有的重启任务

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | - |
| `成功` | false 失败 |


**备注**: 无
