# 9.5.2.1 图像生成会话


> 📌 创建图像生成的会话
> **子模块**: 图像生成 | **编程语言**: C

**原型**:
```c
GenAiImageSession *genai_image_create_session()
```

**描述**: 创建图像生成会话

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `GenAiImageSession*` | 图像生成会话指针 |
