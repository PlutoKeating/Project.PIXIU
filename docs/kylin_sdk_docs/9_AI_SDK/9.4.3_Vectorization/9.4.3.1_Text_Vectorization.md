# 9.4.3.1 文本向量化

添加头文件
`#include <coreai/embedding/embedding.h>`

> 📌 文本向量化会话
> **子模块**: 文本向量化 | **编程语言**: C

**原型**:
```c
TextEmbeddingSession *text_embedding_create_session();
```

**描述**: 创建文本向量化会话

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `TextEmbeddingSession*` | 文本向量化会话指针 |

> 📌 向量化文本（同步）
> **子模块**: 文本向量化
编程语
言
C

**原型**:
```c
bool text_embedding(TextEmbeddingSession *session, const char *text, EmbeddingResult
**result)
```

**描述**: 向量化文本同步接口，需要调用embedding_result_destroy销毁资源

**参数**:

| 参数 | 说明 |
|------|------|
| `session` | 文本向量化会话指针 |
| `text` | 文本 |
| `result` | EmbeddingResult类型指针的地址 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `bool` | 成功时返回true，否则返回false |


---
