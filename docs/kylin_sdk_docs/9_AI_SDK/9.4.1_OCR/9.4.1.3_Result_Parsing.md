> 📌 获取一行文本内容
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
const char *text_line_get_value(TextLine *text_line)
```

**描述**: 获取一行文本中的内容

**参数**:

| 参数 | 说明 |
|------|------|
| `text_line` | TextLine类型的指针 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `const char*` | 返回该行文本的指针 |


---


> 📌 获取文本角点位置
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
PixelPoint *text_line_get_corner_points(TextLine *text_line, int *point_number)
```

**描述**: 获取一行文本的角点位置信息（四个角的位置信息）

**参数**:

| 参数 | 说明 |
|------|------|
| `text_line` | TextLine类型的指针 |
| `point_number` | 角点个数，固定输出为4 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `PixelPoint*` | 返回四个点的坐标，顺序为左上、左下、右上、右下 |


---


> 📌 获取整体文本信息
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
const char *text_recognition_result_get_value(TextRecognitionResult *result)
```

**描述**: 获取识别结果的整体文本信息，不带格式

**参数**:

| 参数 | 说明 |
|------|------|
| `result` | TextRecognitionResult类型的识别结果指针 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `const char*` | 返回所有文本的内容 |

言
