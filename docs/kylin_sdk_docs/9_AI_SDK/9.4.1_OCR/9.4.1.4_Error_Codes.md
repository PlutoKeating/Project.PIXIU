# 9.4.1.4 错误码

通用错误码可参考 9.6 章节，文字识别专有错误码如下：
添加头文件
`#include <coreai/vision/error.h>`

> 📌 文字识别错误码
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
typedef enum { OCR_IMAGE_ERROR = 100, OCR_PARAM_INVALID } OcrErrorCode;
```

**描述**: 文字识别相关的错误码
错误码
OCR_IMAGE_ERROR
数据文件无效
OCR_PARAM_INVALID
参数无效

**参数**: 无

**返回值**: 无
