# 9.4.1.1 文字识别会话

添加头文件
`#include <coreai/vision/textrecognition.h>`

> 📌 创建文字识别会话
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
TextRecognitionSession *text_recognition_create_session()
```

**描述**: 创建文字识别会话

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `TextRecognitionSession*` | 文字识别会话指针 |


---


> 📌 初始化文字识别会话
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
int text_recognition_init_session(TextRecognitionSession *session)
```

**描述**: 初始化文字识别会话

**参数**:

| 参数 | 说明 |
|------|------|
| `session` | 文字识别会话的指针 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 返回初始化的结果，0表示成功，非0表示错误码 |

> 📌 设置结果回调函数
> **子模块**: 文字识别 | **编程语言**: C

**原型**:
```c
void text_recognition_result_set_callback(TextRecognitionSession *session,
TextRecognitionResultCallback callback, void *user_data)
```

**描述**: 设置文字识别结果的回调函数

**参数**:

| 参数 | 说明 |
|------|------|
| `session` | 文字识别会话的指针 |
| `callback` | TextRecognitionResultCallback类型的结果回调函数 |
| `user_data` | 调用者自定义的数据 |
