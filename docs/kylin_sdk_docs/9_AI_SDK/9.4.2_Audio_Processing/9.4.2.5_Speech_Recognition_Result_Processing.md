**原型**:

**参数**:

| 参数 | 说明 |
|------|------|

> 📌 获取发言人的id

**原型**:
```c

```

**描述**: 获取语音识别结果中的说话人id

**参数**:

| 参数 | 说明 |
|------|------|
| `result` | 语音识别结果的指针 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 如果识别到发言人，返回大于0的id；否则返回-1 |
