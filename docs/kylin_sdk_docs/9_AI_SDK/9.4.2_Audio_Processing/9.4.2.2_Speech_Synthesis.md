# 9.4.2.2 语音合成

添加头文件
`#include <coreai/speech/synthesizer.h>`

> 📌 创建语音合成会话
> **子模块**: 语音合成 | **编程语言**: C

**原型**:
```c
SpeechSynthesizerSession *speech_synthesizer_create_session()
```

**描述**: 创建语音合成的会话

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `SpeechSynthesizerSession*` | 语音合成会话的指针 |


---


> 📌 初始化语音合成会话
> **子模块**: 语音合成 | **编程语言**: C

**原型**:
```c
int speech_synthesizer_init_session(SpeechSynthesizerSession *session)
```

**描述**: 初始化语音合成的会话

**参数**:

| 参数 | 说明 |
|------|------|
| `session` | 语音合成会话的指针 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 初始化结果，0表示成功；大于0时表示具体的错误码 |
