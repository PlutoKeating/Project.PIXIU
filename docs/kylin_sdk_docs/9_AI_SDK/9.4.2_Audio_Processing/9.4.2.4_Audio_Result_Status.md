# 9.4.2.4 语音模型配置

1. 可指定当前使用的模型的名称；
2. 具体名称可参考“设置”->“AI管理模块”中配置的名称
添加头文件
`#include <coreai/speech/config.h>`

> 📌 创建模型配置实例
> **子模块**: 音频配置 | **编程语言**: C

**原型**:
```c
SpeechModelConfig *speech_model_config_create()
```

**描述**: 创建模型配置实例

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `SpeechModelConfig *` | 模型配置实例指针 |


---


> 📌 销毁模型配置实例
> **子模块**: 音频配置 | **编程语言**: C

**原型**:
```c
void speech_model_config_destroy(SpeechModelConfig **config)
```

**描述**: 销毁模型配置实例

**参数**:

| 参数 | 说明 |
|------|------|
| `config` | 模型配置实例指针的地址 |


**返回值**: 无

---


> 📌 设置使用的模型名称
> **子模块**: 音频配置 | **编程语言**: C

**原型**:
```c
void speech_model_config_set_name(SpeechModelConfig *config, const char *name)
```

**描述**: 设置模型名称

**参数**:

| 参数 | 说明 |
|------|------|
| `config` | 模型配置的实例指针 |
| `name` | 设置的模型名字 |


**返回值**: 无

---
