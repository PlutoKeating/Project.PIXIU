# 9.1 概述

麒麟 AI SDK 将 AI 能力统一抽象封装为 C 语言接口，屏蔽了各个大模型的接口差异，降低了应用集成 AI 能力
的门槛。麒麟 AI SDK 主要分为传统 AI 能力接口和生成式 AI 能力接口。传统 AI 能力接口包括文字识别、音频
处理和向量化等能力，生成式 AI 能力接口包括文本生成和图像生成等能力接口。
本文档旨在为开发者在银河麒麟系统上进行应用开发时，提供一种高效查阅 AI SDk 接口的声明和使用方法的
方式。减少开发者在使用 AI SDK 时的学习成本。
AI SDK的整体模块介绍如下：
模块
描述
文本生成SDK
提供文本生成相关的能力，包括文本生成、文本对话，内置了多种默认提示词，支持使用
云端和端侧大模型。
图像生成SDK
提供图像生成相关的能力，能够根据文本描述生成对应的图片，支持多种风格、分辨率和
语言等，目前仅支持云端模型。
语音识别/合
成SDK
提供语音识别/合成相关的能力，语音识别支持流式和非流式的形式，支持识别发言人
（依赖云端服务），目前仅支持云端模型。
文字识别SDK
提供文字识别相关的能力，可以将图像中的文字为文本，并提供文本行书和坐标信息等。
目前仅支持使用端侧模型进行识别。
