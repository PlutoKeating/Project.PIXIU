# 9.5.1.4 文本生成错误码

添加头文件
`#include <genai/text/error.h>`
通用错误码可参考 4.3 节，文本生成专用错误码如下：

> 📌 文本生成错误码
> **子模块**: 文本生成 | **编程语言**: C

**原型**:
```c
typedef enum { NLP_INPUT_INVALID = 100, NLP_PARAM_ERROR } GenAiTextErrorCode
```

**描述**: 文本生成相关的错误码
错误码
NLP_INPUT_INVALID
输入文本无效
NLP_PARAM_ERROR
参数错误

**参数**: 无

**返回值**: 无
