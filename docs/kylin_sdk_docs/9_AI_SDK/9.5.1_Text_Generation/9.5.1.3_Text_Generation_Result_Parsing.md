# 9.5.1.3 文本生成结果解析

添加头文件
`#include <genai/text/result.h>`

> 📌 当前版本仅支持流式结果返回获取模型生成的文本结果
> **子模块**: 结果解析 | **编程语言**: C

**原型**:
```c
const char *chat_result_get_assistant_message(ChatResult *result)
```

**描述**: 获取模型生成的文本结果

**参数**:

| 参数 | 说明 |
|------|------|
| `result` | 文本生成结果实例指针 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `文本字符串` | - |
