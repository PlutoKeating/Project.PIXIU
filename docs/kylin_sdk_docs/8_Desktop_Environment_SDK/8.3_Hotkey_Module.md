# 8.3 快捷键模块

安装命令
$sudo apt install libkysdk-shortcut libkysdk-shortcut-dev
构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-shorctu
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-shortcut)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

> 📌 创建一个新的全局快捷键(自3.0.1.0版本启用)
> **子模块**: 快捷键 | **接口类型**: C

**原型**:
```c
int kdk_shortcut_create_global_shortcut(const char *name, const char *key, const char
*action);
```

**描述**: 创建一个新的全局快捷键

**参数**:

| 参数 | 说明 |
|------|------|
| `name` | 快捷键名称（唯一） |
| `key` | 快捷键，例如 Ctrl+Alt+P，快捷键需要 1-2 个控制符 + 一个字符 |
| `action` | 应用的 desktop 文件，或者应用的执行命令 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | 错误码 失败返回错误码 |


**备注**: 无
