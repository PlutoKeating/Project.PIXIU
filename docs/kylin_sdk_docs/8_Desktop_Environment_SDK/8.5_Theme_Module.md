# 8.5 主题模块

安装命令
$sudo apt install libkysdk-thememanager libkysdk-thememanager-dev
构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-thememanager
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-thememanager)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 8.5.1 主题

头文件路径
/usr/include/kysdk/desktop/kthememanager.h
so库路径

```
/usr/lib/*/libkysdk-thememanager.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息

> 📌 获取控制面板当前的公共主题类型(自3.0.1.0版本启用)
> **子模块**: 主题控制模块 | **接口类型**: C++

**原型**:
```c
QString getUkccGlobalTheme();
```

**描述**: 获取控制面板当前的公共主题类型

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `QString` | 公共主题类型Light-Seeking、Heyin、custom |


**备注**: 无
