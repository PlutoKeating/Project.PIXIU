# 8.4 应用行为模块

安装命令
$sudo apt install libkysdk-appmanager libkysdk-appmanager-dev
构建示例
1. pro文件构建示例
CONFIG += link_pkgconfig
PKGCONFIG += kysdk-appmanager
2. CMakeLists文件构建示例
`cmake_minimum_required(VERSION 3.5)`
find_package(PkgConfig REQUIRED)
pkg_check_modules(KYSDK kysdk-appmanager)
target_include_directories(demo PRIVATE ${KYSDK_INCLUDE_DIRS})
target_link_directories(demo PRIVATE ${KYSDK_LIBRARY_DIRS})
target_link_libraries(demo PRIVATE ${KYSDK_LIBRARIES})

#### 8.4.1 应用行为

头文件路径
/usr/include/kysdk/desktop/kappmanager.h
/usr/include/kysdk/desktop/appinfo.h
so库路径

```
/usr/lib/*/libkysdk-appmanager.so
```

'*'代表不同架构的架构目录名称，例如x86_64-linux-gnu
子模块信息
数据结构
```c
    enum KAppType
    {
```
AUDIO,
VIDEO,
IMAGE,
TEXT,
BROWSER,
EMAIL
`    };`

> 📌 获取系统所有应用程序(自3.0.1.0版本启用)
> **子模块**: 应用行为控制 | **接口类型**: C++

**原型**:
```c
QList getApplications();
```

**描述**: 获取系统所有应用程序

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `QList` | 应用程序列表 |


**备注**: 无
