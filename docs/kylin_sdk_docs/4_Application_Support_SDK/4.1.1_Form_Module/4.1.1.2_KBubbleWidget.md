# 4.1.1.2 KBubbleWidget

功能描述：KBubbleWidget，继承自 QWidget，是一个带有气泡尾部的窗体，可以指定气泡尾部的尺
寸、显示方向和显示位置，还可以设置窗体的圆角、毛玻璃以及透明度。自 2.0.0.0 版本启用。
枚举类型
```c
enum TailDirection{ TopDirection, LeftDirection,
BottomDirection, RightDirection, None };
```
```c
enum TailLocation{ LeftLocation, MiddleLocation,
RightLocation };
```

> 📌 设置气泡尾部尺寸（自2.0.0.0版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setTailSize(const QSize& size);
```

**描述**: 设置气泡尾部尺寸

**参数**:

| 参数 | 说明 |
|------|------|
| `QSize` | 尺寸大小 |


**备注**: 无
