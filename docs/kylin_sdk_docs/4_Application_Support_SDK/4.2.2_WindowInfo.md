# 4.2.2 WindowInfo


> 📌 返回窗口是否是最大化状态（自1.2版本启用）
> **子模块**: 窗口管理模块 | **接口类型**: C++

**原型**:
```c
inline bool isMaximized() const;
```

**描述**: 返回窗口是否是最大化状态

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 窗口在最大化状态 false 窗口不在最大化状态 |


**备注**: 无
