# 4.1.17 KFLowLayout

功能描述: 存在水平间距、垂直间距的布局（V11自3.0.1.0启用）

> 📌 创建一个父对象parent，边距为margin，水平间距为hSpace，垂直间距为vSpace的布局
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
explicit KFlowLayout(QWidget *parent, bool home = false, int margin = -1, int hSpacing =
-1, int vSpacing = -1 )
```

**描述**: 创建一个父对象parent，边距为margin，水平间距为hSpace，垂直间距为vSpace的布局

**参数**:

| 参数 | 说明 |
|------|------|
| `parent` | 父指针 |
| `home` | 是否是首页布局 |
| `margin` | 边距 |
| `hspacing` | 水平间距 |
| `vspacing` | 垂直间距 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `KFlowLayout` | - |


**备注**: 无

---
