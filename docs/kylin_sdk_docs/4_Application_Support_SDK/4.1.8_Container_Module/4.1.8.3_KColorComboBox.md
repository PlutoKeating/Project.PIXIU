# 4.1.8.3 KColorComboBox

功能描述：可以选择容器中的任何颜色
枚举类型
```c
enum ComboType{ Circle，RoundedRect};
```

> 📌 以列表形式添加颜色选项（自2.0版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setColorList(const QList& list)
```

**描述**: 以列表形式添加颜色选项

**参数**:

| 参数 | 说明 |
|------|------|
| `list` | 以列表形式添加颜色选项 |


**备注**: 无
