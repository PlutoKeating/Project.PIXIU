# 4.1.8.8 KRadioButtonFrame

功能描述：创建一个带 QButtonGroup 的 Frame，V11自3.0.1.0启用

> 📌 添加一个 id = id 的 QRadioButton 到 m_buttonGroup，并放到 radioLayout 中
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void addButton(QRadioButton *button,int id = -1 , bool addStretch = false)
```

**描述**: 添加一个 id = id 的 QRadioButton 到 m_buttonGroup，并放到 radioLayout 中

**参数**:

| 参数 | 说明 |
|------|------|
| `button` | 需要添加的button指针 |
| `id` | 需要插入的位置 |
| `addStretch` | 是否add stretch |


**备注**: 无
