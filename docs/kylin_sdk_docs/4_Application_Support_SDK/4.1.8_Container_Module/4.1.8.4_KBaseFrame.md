# 4.1.8.4 KBaseFrame

功能描述：基础容器，可基于此类实现其他容器模块，V11自3.0.1.0启用
枚举类型
```c
enum BorderRadiusStyle{ Top，None，Bottom，Around};
```

> 📌 设置圆角风格
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setRadiusType(BorderRadiusStyle style);
```

**描述**: 设置圆角风格

**参数**:

| 参数 | 说明 |
|------|------|
| `icon` | 需要设置的圆角风格 |


**备注**: 无

---


> 📌 获取平板模式
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
bool getTabletMode()
```

**描述**: 获取是否是平板模式

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 是平板模式 false 非平板模式 |


**备注**: 无

---


> 📌 获取是否是一个容器frame
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
bool isContainer()
```

**描述**: 获取是否是一个容器frame

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 是 false 不是 |


**备注**: 无

---


> 📌 设置改frame是否是一个容器frame
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setContainer(bool b =false)
```

**描述**: 设置该frame是否是一个容器frame

**参数**:

| 参数 | 说明 |
|------|------|
| `true` | 是 |
| `false` | 不是 |


**备注**: 无
