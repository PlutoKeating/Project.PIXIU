# 4.1.8.10 KSliderFrame

功能描述: 创建一个带slider的frame（V11自3.0.1.0启用）

> 📌 获取slider
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
KSlider *slider()
```

**描述**: 获取slider

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `KSlider *` | KSlider指针 |


**备注**: 无
