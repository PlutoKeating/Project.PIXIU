# 4.1.8.9 KSettingGroup

功能描述：创建一个 Spacing 为 1 的垂直布局 Frame（V11自3.0.1.0启用）

> 📌 为mainLayout添加控件并更新圆角
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void addWidget(QFrame *item,bool autoUpdateShape = true, bool visible =true)
```

**描述**: 为mainLayout添加控件并更新圆角

**参数**:

| 参数 | 说明 |
|------|------|
| `item` | 需要添加的控件 |
| `autoUpdateShape` | 是否自动更新item圆角样式 |
| `visible` | 设置item是否可见 |


**备注**: 无

---
