#### 4.1.12 标签模块


#### 4.1.12.1 KTag

功能描述：标签，分为默认和可关闭的两种。
枚举类型
枚举类型
```c
enum TagStyle { HighlightTag, BoderTag, BaseBoderTag,
GrayTag, IconTag(since 2.4) };
```

> 📌 设置标签是否可以关闭。（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setClosable(bool flag)
```

**描述**: 设置标签是否可以关闭。

**参数**:

| 参数 | 说明 |
|------|------|
| `true` | 显示关闭按钮，可关闭 |
| `false` | 隐藏关闭按钮，不可关闭 |


**备注**: 无
