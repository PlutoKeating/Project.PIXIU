# 4.1.9 面包屑 KBreadCrumb

功能描述：无边框的标签栏，可以添加文字和图标，支持点击和 hover 高亮。
枚举类型
枚举类型
```c
enum KBreadCrumbType { FlatBreadCrumb,
CubeBreadCrumb };
```

> 📌 设置图标（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setIcon(const QIcon &icon);
```

**描述**: 设置图标

**参数**:

| 参数 | 说明 |
|------|------|
| `icon` | 需要设置给部件的icon |


**备注**: 无

---


> 📌 获取图标（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
QIcon icon() const;
```

**描述**: 获取图标

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `QIcon` | 获取控件的图标 |


**备注**: 无

> 📌 获取KBreadCrumb是否为flat类型。（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
bool isFlat() const;
```

**描述**: 获取KBreadCrumb是否为flat类型。

**参数**:

| 参数 | 说明 |
|------|------|
| `>返回值` | true |
| `flat类型` | false |
| `不是flat类型` | - |


**返回值**: 无

**备注**: 无
