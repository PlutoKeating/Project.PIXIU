# 4.3.1 日志模块


> 📌 用于Qt注册日志函数，不应单独调用(自1.2版本启用)
> **子模块**: 日志模块 | **接口类型**: C++

**原型**:
```c
static void logOutput(QtMsgType type , const QMessageLogContext &context , const
QString &msg);
```

**描述**: 用于Qt注册日志函数，不应单独调用.

**参数**:

| 参数 | 说明 |
|------|------|
| `type` | 日志类型 |
| `context` | 调用打印日志接口文件信息 |
| `msg` | 日志信息 |


**备注**: 无
