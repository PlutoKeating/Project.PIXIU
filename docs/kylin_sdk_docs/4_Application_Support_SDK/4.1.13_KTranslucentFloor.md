# 4.1.13 KTranslucentFloor

KTranslucentFloor，继承自 QFrame，提供一个毛玻璃底板，可以设置圆角以及是否添加阴影效果。
自 1.2.0.12 版本启用。

> 📌 设置圆角半径（自1.2.0.12版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setBorderRadious(int radious);
```

**描述**: 设置圆角半径大小

**参数**:

| 参数 | 说明 |
|------|------|
| `radious` | 设置圆角半径大小 |


**备注**: 无

---


> 📌 返回圆角半径大小（自1.2.0.12版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
int borderRadius();
```

**描述**: 返回圆角半径大小

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 获取圆角半径大小 |


**备注**: 无

---
