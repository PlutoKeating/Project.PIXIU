# 4.1.3.2 搜索输入框

功能描述：可以设置 placeHolder 的文字内容及对齐方式，输入文字的对齐方式，是否启用清除按钮
等。

> 📌 设置是否可用（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setEnabled(bool);
```

**描述**: 设置是否可用

**参数**:

| 参数 | 说明 |
|------|------|
| `true` | 控件可用 |
| `false` | 控件不可用 |


**备注**: 无
