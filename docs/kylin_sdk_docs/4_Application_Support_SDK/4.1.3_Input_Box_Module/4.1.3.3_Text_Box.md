# 4.1.3.3 文本框

功能描述：KTextEdit继承自QTextEdit的文本框，自2.4启用

> 📌 设置label是否可见（自2.4启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setLabelVisible(bool flag)
```

**描述**: 设置label是否可见

**参数**:

| 参数 | 说明 |
|------|------|
| `true` | label可见 |
| `false` | label不可见 |


**备注**: 无

---


> 📌 设置图标（自2.4版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setPixmap(const QPixmap &pixmap)
```

**描述**: 设置图标

**参数**:

| 参数 | 说明 |
|------|------|
| `pixmap` | 将pixmap设置给label |


**备注**: 无

---


> 📌 获取图标（自2.4版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
const QPixmap *pixmap()const
```

**描述**: 获取图标

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `QPixmap*` | 返回label的QPixmap |


**备注**: 无

---

void setLabelText(const QString &text)
