# 4.1.7.3 KSecurityLevelBar

功能描述：密码强度提示条，用于指示密码强度等级。分为低，中，高三个等级，等级具体划分策略由
应用程序指定。
枚举类型
枚举类型
```c
enum SecurityLevel{Low,Medium,High} ;
```

> 📌 设置安全等级（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setSecurityLevel(SecurityLevel level);
```

**描述**: 设置安全等级

**参数**:

| 参数 | 说明 |
|------|------|
| `level` | 枚举 设置安全等级 |


**备注**: 无

---


> 📌 获取安全等级（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
SecurityLevel securityLevel();
```

**描述**: 获取安全等级

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `SecurityLevel` | 获取安全等级 |


**备注**: 无
