# 4.1.7.1 KBadge

功能描述：消息提醒气泡。可以设置提示信息数值，字体大小，背景色。

> 📌 返回当前值（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
int value();
```

**描述**: 返回当前值

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 返回当前值 |


**备注**: 无

---


> 📌 设置值，最大显示数值为999，大于999显示"..."（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setValue(int value);
```

**描述**: 设置值，最大显示数值为999，大于999显示"..."

**参数**:

| 参数 | 说明 |
|------|------|
| `value` | 设置当前值 |


**备注**: 无

---
