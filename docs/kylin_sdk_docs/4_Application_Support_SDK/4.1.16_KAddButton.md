# 4.1.16 KAddButton

功能描述: 添加按钮（V11自3.0.1.0启用）

> 📌 设置圆角模式
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setRadiusType(KBaseFrame::BorderRadiusStyle style)
```

**描述**: 设置圆角模式

**参数**:

| 参数 | 说明 |
|------|------|
| `style` | 需要设置的圆角模式 |


**备注**: 无

---


> 📌 获取平板模式
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
bool getTableMode()
```

**描述**: 获取平板模式

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 平板模式 false 非平板模式 |


**备注**: 无
