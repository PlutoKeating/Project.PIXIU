> 📌 设置colorButton背景色（自2.0版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setBackgoundColor(QColor color)
```

**描述**: 设置colorButton背景色

**参数**:

| 参数 | 说明 |
|------|------|
| `color` | 设置button背景色 |


**备注**: 无
