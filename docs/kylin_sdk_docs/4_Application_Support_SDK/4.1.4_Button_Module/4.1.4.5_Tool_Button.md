# 4.1.4.5 工具按钮

功能描述：KToolButton，继承自 QToolButton，支持三种样式，支持 loading状态，支持是否显示下
拉按钮。
枚举类型
枚举类型
```c
enum KToolButtonType{Flat,SemiFlat,Background};
```

> 📌 返回类型(自1.2版本启用)
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
KToolButtonType type();
```

**描述**: 返回类型

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `KToolButtonType` | toolbutton类型 |


**备注**: 无

---


> 📌 设置类型（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setType(KToolButtonType type);
```

**描述**: 设置类型

**参数**:

| 参数 | 说明 |
|------|------|
| `type` | 设置toolbutton的类型 |


**备注**: 无

---


> 📌 设置Icon（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setIcon(const QIcon& icon);
```

**描述**: 设置Icon

**参数**:

| 参数 | 说明 |
|------|------|
| `icon` | 为toolbutton设置的图标 |


**备注**: 无

---


> 📌 设置正在加载状态,仅不带箭头的toolbuttuon支持该状态（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setLoading(bool flag);
```

**描述**: 设置正在加载状态,仅不带箭头的toolbuttuon支持该状态

**参数**:

| 参数 | 说明 |
|------|------|
| `true` | 加载状态 |
| `false` | 正常状态 |


**备注**: 无

---


> 📌 获取是否正在加载（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
bool isLoading();
```

**描述**: 获取是否正在加载

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 加载状态 false 正常状态 |


**备注**: 无

---

> 📌 设置是否显示向下箭头，默认不显示（自1.2版本启用）

**参数**:

| 参数 | 说明 |

| `false` | 不显示箭头 |


**备注**: 无
