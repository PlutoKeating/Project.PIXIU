> 📌 设置文本（自2.4版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c

```

**描述**: 设置文本

**参数**:

| 参数 | 说明 |
|------|------|
| `str` | 设置的文本内容 |
