# 4.1.4.2 无边框按钮

功能描述：KboderlessButton,继承自 QPushButton,样式上进行了封装。同样可以可以通过
setPalette()进一步调整样式。
QPushButton 中的各接口均适用，支持四种构造方法。

> 📌 仅一个button（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
KBorderlessButton(QWidget* parent = nullptr);
```

**描述**: 仅一个button

**参数**:

| 参数 | 说明 |
|------|------|
| `parent` | 父类 |


**备注**: 无

---


> 📌 构造一个带文本button（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
KBorderlessButton(const QString &text, QWidget *parent = nullptr);
```

**描述**: 构造一个带文本button

**参数**:

| 参数 | 说明 |
|------|------|
| `text` | 给button设置的文本 |
| `parent` | 父类 |


**备注**: 无

---


> 📌 构造一个带文本和图标的button（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
KBorderlessButton(const QIcon &icon, const QString &text, QWidget *parent = nullptr);
```

**描述**: 构造一个带文本和图标的button

**参数**:

| 参数 | 说明 |
|------|------|
| `icon` | 给button设置的图标icon |
| `text` | 给button设置的文本 |
| `parent` | 父类 |


**备注**: 无
