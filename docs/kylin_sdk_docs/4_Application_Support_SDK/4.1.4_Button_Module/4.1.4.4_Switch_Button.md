# 4.1.4.4 开关按钮

功能描述：KSwitchButton，继承自 QPushButton，对按钮进行了重绘，用于指示开/关状态。

> 📌 设置是否可选中（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setCheckable(bool);
```

**描述**: 设置是否可选中

**参数**:

| 参数 | 说明 |
|------|------|
| `true` | 可选中 |
| `false` | 不可选中 |


**备注**: 无

---


> 📌 获取是否可选中（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
bool isCheckable() const;
```

**描述**: 获取是否可选中

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `true` | 可选中 false 不可选中 |


**备注**: 无

---

> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:


**描述**: 获取是否选中

**参数**: 无

**返回值**:
