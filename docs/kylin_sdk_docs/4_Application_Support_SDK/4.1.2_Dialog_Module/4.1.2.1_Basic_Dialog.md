# 4.1.2.1 基础对话框

功能描述：KDialog，继承自 QDialog 支持响应主题背景切换，相应图标主题切换，窗口按钮样式符合
ukui3.1 的设计风格，标题颜色响应窗口激活状态。

> 📌 设置对话框图标（自1.2.0版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setWindowIcon(const QIcon &icon);
```

**描述**: 设置对话框图标

**参数**:

| 参数 | 说明 |
|------|------|
| `QIcon` | 设置图标QIcon |


**备注**: 无

---


> 📌 直接根据图标名称设置窗口图标，例如：dialog->setWindowIcon("kylin-music");（自1.2.0版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setWindowIcon(const QString& iconName);
```

**描述**: 直接根据图标名称设置窗口图标，例如：dialog->setWindowIcon("kylin-music");

**参数**:

| 参数 | 说明 |
|------|------|
| `QString` | 需要设置的图标名称 |


**备注**: 无
