# 4.1.2.2 关于对话框

功能描述：KAboutDialog，包含的主要内容有：应用图标，应用名称，版本号，团队邮箱以及具体的
应用描述，注意，默认应用描述是不显示的。可以通过 setBodyTextVisible(bool)控制其是否需要显
示。

> 📌 获取左边栏widget（自1.2.0版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
QWidget* sideBar();
```

**描述**: 获取左边栏widget

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `QWidget*` | 返回侧边widget |


**备注**: 无

---
