# 4.1.5.2 KWindowButtonBar

功能描述：KWidget 和 KDialog 的一个组成部分，用于下拉菜单、最小化、最大化、关闭按钮。
枚举类型
枚举类型
```c
enum MaximumButtonState{Maximum,Restore};
```

> 📌 获取最小化按钮（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
QPushButton* minimumButton();
```

**描述**: 获取最小化按钮

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `QPushButton*` | 获取最小化按钮 |


**备注**: 无
