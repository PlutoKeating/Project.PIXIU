# 4.1.5.6 导航栏

功能描述：KNavigationBar，支持显示三种样式的 item，带图标的表示一级导航的 item，不带图标的
表示二级的导航 item，还有表示组别的灰色字体的item。

> 📌 增加常规Item（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void addItem(QStandardItem*item);
```

**描述**: 增加常规Item

**参数**:

| 参数 | 说明 |
|------|------|
| `item` | 需要增加的常规Item |


**备注**: 无

---
