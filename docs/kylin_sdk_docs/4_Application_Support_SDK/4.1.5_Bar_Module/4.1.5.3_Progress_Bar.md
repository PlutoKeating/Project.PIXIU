# 4.1.5.3 进度条

功能描述：KProgressBar，继承自 QProgressBar，支持三种状态：正常、完成和失败，支持是否显示
进度值，支持水平和竖直。
枚举类型
枚举类型
enum
ProgressBarState{NormalProgress,FailedProgress,SuccessProgress};

> 📌 获取状态（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
ProgressBarState state();
```

**描述**: 获取状态

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `ProgressBarState` | 获取状态 |


**备注**: 无
