# 4.1.5.1 KIconBar

功能描述：KWidget 和 KDialog 的一个组成部分，用于显示图标和窗口名称，2.4新增。

> 📌 设置图标名称（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setIcon(const QString& iconName);
```

**描述**: 设置图标名称

**参数**:

| 参数 | 说明 |
|------|------|
| `iconName` | 需要设置的图标名称 |


**备注**: 无

---


> 📌 设置图标（自2.4版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setIcon(const QIcon& icon);
```

**描述**: 设置图标

**参数**:

| 参数 | 说明 |
|------|------|
| `icon` | button设置的图标 |


**备注**: 无

---
