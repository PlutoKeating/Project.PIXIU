# 4.1.5.4 KProgressCircle

环形进度条，支持三种状态：正常、完成和失败，支持是否显示进度值。

> 📌 获取环形进度条的最小值。（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
int minimum() const
```

**描述**: 获取环形进度条的最小值。

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 获取环形进度条的最小值。 |


**备注**: 无
