# 4.1.5.5 KTabBar

功能描述：继承自 QTabBar
枚举类型
枚举类型
```c
enum KTabBarStyle{SegmentDark,SegmentLight,Sliding} ;
```

> 📌 设置TabBar样式（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
void setTabBarStyle(KTabBarStyle barStyle);
```

**描述**: 设置TabBar样式

**参数**:

| 参数 | 说明 |
|------|------|
| `barStyle` | 设置tabbar的样式 |


**备注**: 无

---


> 📌 返回TabBar样式（自1.2版本启用）
> **子模块**: qt控件扩展模块 | **接口类型**: C++

**原型**:
```c
KTabBarStyle barStyle();
```

**描述**: 返回TabBar样式

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `KTabBarStyle` | 返回tabbar的样式 |


**备注**: 无

---


> 📌 设置圆角半径，只对SegmentDark，SegmentLight样式生效（自1.2版本启用）

**原型**:
```c

```

**描述**: 设置圆角半径，只对SegmentDark，SegmentLight样式生效

**参数**:

| 参数 | 说明 |
|------|------|
| `radius` | 设置控件圆角半径 |


**备注**: 无
