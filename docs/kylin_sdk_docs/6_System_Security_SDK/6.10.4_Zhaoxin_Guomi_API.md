# 6.10.4 兆芯国密接口

兆芯GMI国密接口提供了openssl引擎支持和单独的开发库zx_gmilib。zx_gmilib 是兆芯 GMI Linux 开发库。该开发库目前所
支持的运行环境是 Linux 64 位环境,对外提供两个文件,分别是动态库 libgmi.so 和头文件 gmi.h。它是一个 C Library,封
装
了兆芯 CPU 原生支持的 SM2/SM3/SM4/RNG 指令,提供了在这些兆芯 CPU 上执行SM2/SM3/SM4/RNG 相关指令运算的 C 语言
API,其输入输出格式默认兼容于 Openssl 相关算法 API 的输入输出格式。
兆芯KX-6000G或更新的CPU才支持sm2算法。
依赖包：zx-gmilib 1.4.0.0-0k1.0 或更高版本
openssl_1.1.1f-1kylin2.17k0.8或更高版本
示例见/usr/share/zx-gmilib/example目录。
openssl引擎
兆芯国密openssl引擎支持sm3、sm4。
openssl引擎库地址：/usr/lib/x86_64-linux-gnu/engines-1.1/gmi.so
