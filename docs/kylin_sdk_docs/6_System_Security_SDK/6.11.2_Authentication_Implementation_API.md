> **子模块**: 认证管理 | **接口类型**: C

**原型**:
```c
int pam_sm_authenticate(pam_handle_t *pamh, int flags, int argc,const char **argv)
```

**描述**: pam身份认证模块接口

**参数**:

| 参数 | 说明 |
|------|------|
| `pamh` | 参数由认证程序与配置文件传入 |
| `flags` | argc |
| `argv` | - |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `成功时返回PAM_SUCCESS` | 失败时返回PAM_AUTH_ERR, PAM_ABORT, PAM_CRED_INSUFFICIENT, PAM_AUTHINFO_UNAVAIL, PAM_MAXTRIES, PAM_USER_UNKNOWN等 |


**备注**: 该接口由 pam 模块开发人员自行实现,接口名称与参数固定
