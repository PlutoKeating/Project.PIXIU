# 6.1.3 桌面应用管控

D-BUS接口：
名称：com.kylin.kysdk.softwarecontrol
路径：/com/kylin/kysdk/peony
接口：com.kylin.kysdk.peony

> 📌 设置管控模式(自1.2.0版本启用)
> **子模块**: 1.设置管控模式 | **接口类型**: C

**原型**:
```c
int kdk_desktop_set_model(int type);
```

**描述**: 调用此接口传入模式ID设置管控模式

**参数**:

| 参数 | 说明 |
|------|------|
| `type` | 模式ID(kdk_model_type枚举值) |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 0-成功，非0-失败 |


**备注**: 无

---
