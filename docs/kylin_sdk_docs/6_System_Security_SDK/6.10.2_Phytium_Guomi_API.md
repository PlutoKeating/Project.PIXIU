# 6.10.2 飞腾国密接口

飞腾国密加速硬件SCTO(SM CRYPTO)是FT2000/4、D2000提供的硬件加速解决方案，硬件支持SM2/SM3/SM4算法。SM2为非对称加
密，SM3为消息摘要算法，校验结果为256位。SM4为对称加密算法，密钥长度和分组长度均为128位。
飞腾国密加速驱动包括SCTO驱动以及应用层软件OpenSSL。
SCTO驱动包括用户层驱动和内核层驱动两部分，其中用户层驱动可供OpenSSL等应用层使用，内核层驱动可供内核模块使用。
SCTO用户层驱动实现了用户层API接口，此外，飞腾基于用户层API接口开发了OpenSSL SCTO 引擎。目前SCTO引擎已支持SM3、
CBC(SM4)、ECB(SM4)和CTR(SM4)算法。其中，OpenSSL引擎机制目的是为了能够透明地使用第三方提供的软件加密库或者硬件加
密设备进行加密。它使OpenSSL不仅仅只是一个加密库，而是提供了一个通用加密接口，能够与其他加密库或者加密设备协调工
作。用户可以通过OpenSSL标准接口，即可实现对飞腾国密加速硬件使用。
SCTO内核层驱动实现了将SM2、SM3、SM4算法注册到Kernel Crypto框架中，可供内核中其它模块如：tcrypt以及应用如：dm-
crypt等使用。
依赖包：phytium-scto_2.0.0.1-0k0.1 或更高版本
openssl_1.1.1f-1kylin2.16k3或更高版本

lib_sm2_phutium.h
lib_sm3_phutium.h
