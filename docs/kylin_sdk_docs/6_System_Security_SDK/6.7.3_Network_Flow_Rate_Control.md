# 6.7.3 网络流速管控


**安装命令：**


```bash
$ sudo apt-get install kysdk-netflow-control
```

dbus 服务名称：com.kylin.kysdk.netflowcontrol
路径名称：/com/kylin/kysdk/netflowcontrol
Interfaces：com.kylin.kysdk.netflowcontrol.server

子模块信息

> 📌 设置网卡流速管控开关状态(自1.0.0.1版本启用)
> **子模块**: 网络流速管控 | **接口类型**: DBus

**原型**:
```c
setNicCtlStatus (Int32 status) ↦ (Int32 arg_1)
```

**描述**: 设置网卡流速管控开关状态

**参数**:

| 参数 | 说明 |
|------|------|
| `status` | 管控状态(0 关闭；1 开启) |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | - |
| `-1` | 失败 |


**备注**: 无

示例代码：
from gi.repository import GLib, Gio
import dbus
`def main():`
# 连接到系统总线
bus = dbus.SystemBus()
# 获取远程对象
remote_object = bus.get_object('com.kylin.kysdk.netflowcontrol', '/com/kylin/kysdk/netflowcontrol')
# 使用D-Bus接口
interface = dbus.Interface(remote_object, 'com.kylin.kysdk.netflowcontrol.server')
# 设置网卡流速管控开启
nic_status = 1
try:
result = interface.setNicCtlStatus(nic_status)
print("设置网卡管控结果:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 设置网卡上传流速限制(单位KB/s)
nic_espeed = 2500
try:
result = interface.setNicEgressSpeed(nic_espeed)
print("设置网卡上传管控结果:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 设置网卡下载流速限制(单位KB/s)
nic_inspeed = 3000
try:
result = interface.setNicIngressSpeed(nic_inspeed)
print("设置网卡下载管控结果:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 设置应用流速管控(覆盖原应用管控配置)
app_speedctl = "[{\"app\":\"openssh-client\",\"egress_spd\":1000,\"ingress_spd\":0},
`{\"app\":\"qaxbrowser-safe-stable\",\"egress_spd\":0,\"ingress_spd\":1500}]"`
try:
result = interface.setAppSpeedCtl(app_speedctl)
print("设置应用管控结果:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 获取网卡流速管控状态
try:
result = interface.getNicCtlStatus()
print("网卡管控状态:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 获取网卡上传流速限制(单位KB/s)
try:
result = interface.getNicEgressSpeed()
print("网卡上传流速限制:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 获取网卡下载流速限制(单位KB/s)
try:
result = interface.getNicIngressSpeed()
print("网卡下载流速限制:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 获取应用流速管控配置
try:
appctl = interface.getAppSpeedCtl()
print("应用管控配置:", appctl)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
# 清空应用流速管控配置
try:
result = interface.clearAppSpeedCtl()
print("清空应用管控结果:", result)
except dbus.DBusException as e:
print("Error calling D-Bus method:", e)
if __name__ == '__main__':
main()
