名称:com.kylin.kysdk.softwarecontrol
路径:/com/kylin/kysdk/ukui_control_center
接口:com.kylin.kysdk.controlcenter

> 📌 设置功能模块是否可见(自1.2.0版本启用)
> **子模块**: 设置功能模块是否可见 | **接口类型**: C

**原型**:
```c
int kdk_controplpanel_set_module_visible(int module, bool visible);
```

**描述**: 调用此接口传入模块名以及是否可见的bool值

**参数**:

| 参数 | 说明 |
|------|------|
| `module` | 模块ID(kdk_controlpanel_module枚举值) |
| `visible` | true-可见，false-隐藏 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 0-成功，非0-失败 |


**备注**: 无

> 📌 获取控制面板是否可见(自1.2.0版本启用)
> **子模块**: 获取控制面板是否可见 | **接口类型**: C

**原型**:
```c
bool kdk_controlpanel_get_module_visible(int module);
```

**描述**: 获取模块是否可见，传入模块ID，返回该模块的结果

**参数**:

| 参数 | 说明 |
|------|------|
| `module` | 模块ID(kdk_controlpanel_module枚举值) |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | true-可见，false-隐藏 |


**备注**: 无

---


> 📌 设置控制面板状态(自2.4.0版本启用)
> **子模块**: 设置控制面板状态 | **接口类型**: C

**原型**:
```c
int kdk_controplpanel_set_module_status(int module, int status);
```

**描述**: 调用此接口传入模块名和模块状态

**参数**:

| 参数 | 说明 |
|------|------|
| `module` | 模块ID(kdk_controlpanel_module枚举值) |
| `status` | 0-隐藏 1-可见 2-禁用 3-启用 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `bool` | 0-成功，非0-失败 |


**备注**: 无

---


> 📌 批量设置控制面板状态(自1.2.0版本启用)
> **子模块**: 批量设置控制面板状态 | **接口类型**: Dbus

**原型**:
```c
int SetStatusList(array(int module,int status))
```

**描述**: 调用此接口传入模块名和模块状态的数组

**参数**:

| 参数 | 说明 |
|------|------|
| `module` | 模块ID(kdk_controlpanel_module枚举值) |
| `status` | 0-隐藏 1-可见 2-禁用 3-启用 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 0-成功，非0-失败 |


**备注**: module中大于1024枚举,status中2,3为版本(2.4.0)中扩展
