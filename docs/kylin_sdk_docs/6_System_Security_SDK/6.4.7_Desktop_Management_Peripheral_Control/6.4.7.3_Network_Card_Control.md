# 6.4.7.3 网卡管控

封装 DBus 接口设置无线网卡管控（该功能需麒麟授权，如果需要使用，请联系麒麟技术开发人员）
服务说明： 自libkysdk-desktopctrl 1.2.0.9-0k1.2版本起，取消了桌管外设管控服务自启动，若需使用
相关功能请启动以下服务：
# 桌面管控设备插拔监控服务：

```bash
$ sudo systemctl enable kylin-mdm-monitor.service
```


```bash
$ sudo systemctl start kylin-mdm-monitor.service
```

# 网卡管控DBus服务：

```bash
$ sudo systemctl enable dbus-com.kylin.mdm.netcardcontrol.service
```


```bash
$ sudo systemctl start dbus-com.kylin.mdm.netcardcontrol.service
```

DBus信息
dbus 服务名称：com.kylin.kysdk.netcardcontrol
路径名称：/com/kylin/kysdk/netcardcontrol
Interfaces：com.kylin.kysdk.netcardcontrol
信号：无
子模块信息

> 📌 设置无线网卡管控状态(自1.2.0.8版本启用)
> **子模块**: 网卡管控 | **接口类型**: DBus

**原型**:
```c
SetNetcardStatus (Int32 status) ↦ (Int32 arg_1)
```

**描述**: 设置无线网卡管控状态

**参数**:

| 参数 | 说明 |
|------|------|
| `status` | 管控状态(0 禁用；1 启用) |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | 其他 失败 |


**备注**: 无

---


> 📌 获取无线网卡管控状态(自1.2.0.8版本启用)
> **子模块**: 网卡管控 | **接口类型**: DBus

**原型**:
```c
GetNetcardStatus () ↦ (Int32 arg_0)
```

**描述**: 获取无线网卡管控状态

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | 禁用 1 启用 其他 失败 |


**备注**: 无
