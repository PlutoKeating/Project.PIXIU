子模块信息

> 📌 设置光驱管控状态(自2.3.0.0版本启用)
> **子模块**: 光驱管控 | **接口类型**: C

**原型**:
```c
int kdk_device_set_cdrom_status(int status)
```

**描述**: 设置光驱管控状态

**参数**:

| 参数 | 说明 |
|------|------|
| `status` | 光驱管控状态，参见 kdk_cdrom_status |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | -5000 门禁管控禁止访问 其他 失败 |


**备注**: typedef enum _kdk_cdrom_status {
KDK_CDROM_ENABLE = 1, //启用刻录机
KDK_CDROM_DISABLE = 2, //禁用刻录机
KDK_CDROM_RO = 5, //只读刻录机
} kdk_cdrom_status;

---


> 📌 获取光驱管控状态(自2.3.0.0版本启用)
> **子模块**: 光驱管控 | **接口类型**: C

**原型**:
```c
int kdk_device_get_cdrom_status()
```

**描述**: 获取光驱管控状态

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `1` | 启用 2 禁用 5 只读 -5000 门禁管控禁止访问 其他 失败 |


**备注**: 无
