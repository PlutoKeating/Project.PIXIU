# 6.1.7 屏保管控

名称：com.kylin.kysdk.systemsettings
路径：/com/kylin/kysdk/screensaver
接口：com.kylin.kysdk.screensaver

> 📌 屏保管控设置屏保图片(自1.2.0版本启用)
> **子模块**: 屏保管控设置屏保图片 | **接口类型**: C

**原型**:
```c
int kdk_screensaver_set_file(const char *path);
```

**描述**: 设置屏保图片

**参数**:

| 参数 | 说明 |
|------|------|
| `path` | 文件路径 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 0-成功，非0-失败 |


**备注**: 无
