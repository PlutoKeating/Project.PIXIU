# 6.10.3 海光国密接口

海光密码技术HCT提供“密码算法加速引擎”和“密钥管理”两个功能。海光密码技术引擎API: 提供国密SM2加解密、SM2签名验签、
SM3哈希、SM4对称加解密通用操作
依赖包：hct 1.0.1

> 📌 hct库使用接口
> **子模块**: 密码设施 | **接口类型**: C

**原型**:
```c
int hct_ccp_init(size_t dma_mem_size)
```

**描述**: 初始化hct算法

**参数**:

| 参数 | 说明 |
|------|------|
| `dma_mem_size` | [in]一般为0，默认为每个ccp分配2M内存 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `成功>0；失败返回其他` | - |


**备注**: 无
