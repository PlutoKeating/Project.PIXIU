# 6.1.2 开始菜单管控

D-BUS接口：
名称：com.kylin.kysdk.softwarecontrol
路径：/com/kylin/kysdk/ukui_menu
接口：com.kylin.kysdk.ukui_menu
** 管控模式ID：**
```c
typedef enum _kdk_model_type {
    MODEL_NORMAL = 0,
    MODEL_BLACKLIST,
    MODEL_WHITELIST,
} kdk_model_type;
```

> 📌 设置开始菜单管控模式(自1.2.0版本启用)
> **子模块**: 1.设置开始菜单管控模式 | **接口类型**: C

**原型**:
```c
int kdk_startmenu_set_model(int type);
```

**描述**: 调用此接口传入模式ID设置开始菜单管控模式

**参数**:

| 参数 | 说明 |
|------|------|
| `type` | 模式ID(kdk_model_type枚举值) |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 0-成功，非0-失败 |


**备注**: 无

---
