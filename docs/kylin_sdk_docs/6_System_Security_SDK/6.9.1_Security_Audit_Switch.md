# 6.9.1 安全审计开关

设置和获取安全审计开关状态

**头文件路径：**

`#include <audit_status_utils.h>`

**so库路径：**


```
/usr/lib/x86_64-linux-gnu/libaudit_status_utils.so
```

子模块信息

> 📌 获取系统审计开关状态
> **子模块**: 安全审计 | **接口类型**: C

**原型**:
```c
int get_audit_status();
```

**描述**: 获取系统审计开关状态

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | 内核及上层均未开启 1 内核开启上层未开启 2 内核未开启上层开启 3 内核及上层均已开启 |
| `-1` | 获取失败 |


---


> 📌 设置系统审计开关状态
> **子模块**: 安全审计 | **接口类型**: C

**原型**:
```c
int set_audit_status(int _switch);
```

**描述**: 设置系统审计开关状态

**参数**:

| 参数 | 说明 |
|------|------|
| `_switch` | 0 关闭系统内核审计；1 打开系统内核审计 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | - |
| `-1` | 设置失败 |


---
