**头文件路径：**

```

```


**子模块信息：**


> 📌 设置应用审计日志状态(自1.2.0.9-0k0.2版本启用)
> **子模块**: 应用行为审计 | **接口类型**: C

**原型**:
```c
int kdk_set_app_audit_status(int apptype, int status)
```

**描述**: 设置应用审计日志状态

**参数**:

| 参数 | 说明 |
|------|------|
| `apptype` | 应用类型（1：麒麟打印 2：麒麟刻录） |
| `status` | 状态（0：关闭 1：开启） |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | -5000 门禁管控禁止访问 非零 失败 |


**备注**: 无

---


> 📌 获取应用审计日志状态(自1.2.0.9-0k0.2版本启用)
> **子模块**: 应用行为审计 | **接口类型**: C

**原型**:
```c
int kdk_get_app_audit_status(int apptype)
```

**描述**: 获取应用审计日志状态

**参数**:

| 参数 | 说明 |
|------|------|
| `apptype` | 应用类型（1：麒麟打印 2：麒麟刻录） |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | 关闭 1 开启 -5000 门禁管控禁止访问 其他 失败 |


**备注**: 无
