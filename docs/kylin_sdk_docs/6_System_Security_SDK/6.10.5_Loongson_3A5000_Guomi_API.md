# 6.10.5 龙芯3a5000国密接口

龙芯3a5000支持sm2、sm3、sm4、随机数算法。
依赖包：westone-3a5000sdf_1.1.0
使用说明见/opt/westone目录。

| `pucPublicKey` | [in]外部 ECC 公钥结构 |
| `pucData` | [in]缓冲区指针,用于存放外部输入的数据 |
| `uiDataLength` | [in]输入的数据长度 |
| `pucEncData` | [out]缓冲区指针,用于存放输出的数据密文 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `成功返回0；失败返回其他` | - |
