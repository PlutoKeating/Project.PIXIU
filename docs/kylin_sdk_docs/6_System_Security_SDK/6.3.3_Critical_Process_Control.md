子模块信息

> 📌 设置关键进程(自1.2.0.9-0k7.0版本启用)
> **子模块**: 关键进程控制 | **接口类型**: C

**原型**:
```c
int kdk_process_set_key_process(const char *filepath)
```

**描述**: 设置关键进程

**参数**:

| 参数 | 说明 |
|------|------|
| `filepath` | 文件路径 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `设置成功` | 1 节点已存在 -5000 门禁管控禁止访问 其他 设置失败 |


**备注**: 无

---


> 📌 取消设置关键进程(自1.2.0.9-0k7.0版本启用)
> **子模块**: 关键进程控制 | **接口类型**: C

**原型**:
```c
int kdk_process_cancel_key_process(const char *filepath)
```

**描述**: 取消设置关键进程

**参数**:

| 参数 | 说明 |
|------|------|
| `filepath` | 文件路径 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `设置成功` | -5000 门禁管控禁止访问 其他 设置失败 |


**备注**: 无

---


> 📌 获取关键进程列表(自1.2.0.9-0k7.0版本启用)
> **子模块**: 关键进程控制 | **接口类型**: C

**原型**:
```c
char **kdk_process_get_key_process(int *count)
```

**描述**: 获取关键进程列表

**参数**:

| 参数 | 说明 |
|------|------|
| `count` | 节点数量 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `char **` | 关键进程列表，使用完需手动释放字符串数组 |


**备注**: 无
