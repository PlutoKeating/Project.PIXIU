子模块信息

> 📌 设置WIFI管控状态(自1.2.0.9-0k7.0版本启用)
> **子模块**: WIFI管控 | **接口类型**: C

**原型**:
```c
int kdk_device_set_wireless_wifi_status(int status)
```

**描述**: 设置WIFI管控状态

**参数**:

| 参数 | 说明 |
|------|------|
| `status` | 管控状态，参见kdk_wifi_status |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | -5000 门禁管控禁止访问 其他 失败 |


**备注**: typedef enum _kdk_wifi_status {
KDK_WIFI_DISABLE = 0,
KDK_WIFI_ENABLE,
} kdk_wifi_status;
