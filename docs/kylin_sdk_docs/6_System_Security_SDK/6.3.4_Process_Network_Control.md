# 6.3.4 进程联网控制

封装 C 接口设置进程联网控制

**头文件路径：**

`#include "kysdk/kysdk-security/libkyprocesssec.h"`

**so库路径：**


```
/usr/lib/kysdk/kysdk-security/libkyprocesssec.so
```

子模块信息

> 📌 设置进程可以联网(自1.2.0.9-0k1.0版本启用)
> **子模块**: 进程联网控制 | **接口类型**: C

**原型**:
```c
int kdk_process_enable_networking(const char *filepath)
```

**描述**: 设置进程可以联网

**参数**:

| 参数 | 说明 |
|------|------|
| `filepath` | 文件路径 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `设置成功` | -5000 门禁管控禁止访问 其他 设置失败 |


**备注**: 无

---


> 📌 设置进程不可联网(自1.2.0.9-0k1.0版本启用)
> **子模块**: 进程联网控制 | **接口类型**: C

**原型**:
```c
int kdk_process_disable_networking(const char *filepath)
```

**描述**: 设置进程不可联网

**参数**:

| 参数 | 说明 |
|------|------|
| `filepath` | 文件路径 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `设置成功` | -5000 门禁管控禁止访问 其他 设置失败 |


**备注**: 无
