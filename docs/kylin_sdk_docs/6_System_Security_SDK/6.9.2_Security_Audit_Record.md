# 6.9.2 安全审计记录

安全审计记录接口

**头文件路径：**

`#include <libaudit.h>`

**so库路径：**


```
/usr/lib/x86_64-linux-gnu/libaudit.so
```

子模块信息

> 📌 打开与内核审计子系统的通信连接
> **子模块**: 安全审计 | **接口类型**: C

**原型**:
```c
extern int audit_open(void);
```

**描述**: 打开与内核审计子系统的通信连接

**参数**: 无

**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | socket文件描述符 |
| `-1` | - |
| `打开失败` | - |


---


> 📌 关闭与内核审计子系统的通信连接
> **子模块**: 安全审计 | **接口类型**: C

**原型**:
```c
extern void audit_close(int fd);
```

**描述**: 关闭与内核审计子系统的通信连接

**参数**:

| 参数 | 说明 |
|------|------|
| `fd` | audit_open()成功时返回的socket文件描述符 |


---


> 📌 记录用户通用审计日志
> **子模块**: 安全审计 | **接口类型**: C

**原型**:
```c
extern int audit_log_user_message(int audit_fd, int type, const char* message, const char
*hostname, const char *addr, const char *tty, int result);
```

**描述**: 记录用户通用审计日志

**参数**:

| 参数 | 说明 |
|------|------|
| `audit_fd` | audit_open调用成功时返回的socket文件描述符 |
| `type` | 审计日志类型，如AUDIT_USER_LOGIN，AUDIT_TEST等 |
| `message` | 待发送的审计日志信息 |
| `hostname` | 主机名，若不清楚，可设为NULL |
| `addr` | 用户的网络地址，若不清楚，可设为NULL |
| `tty` | 用户使用的tty，若不清楚，可设为NULL |
| `result` | 审计结果，1表示“成功”，0表示“失败” |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `int` | 发送序列号，大于0表示发送成功，小于等于0表示发送失败 |
