# 6.12 安全模块

麒麟操作系统内核安全模块

#### 6.12.1 LSM安全模块


**头文件路径：**

` #include <linux/security_ops.h>`

**子模块信息：**


> 📌 添加自定义LSM模块
> **子模块**: LSM安全模块 | **接口类型**: C

**原型**:
```c
int security_add_external_ops(struct security_operations *ops)
```

**描述**: 添加自定义LSM模块

**参数**:

| 参数 | 说明 |
|------|------|
| `ops` | LSM模块的钩子函数集合 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | -errno 失败 |


**备注**: 无

---


> 📌 删除自定义LSM模块
> **子模块**: LSM安全模块 | **接口类型**: C

**原型**:
```c
void security_del_external_ops(struct security_operations *ops)
```

**描述**: 删除自定义LSM模块

**参数**:

| 参数 | 说明 |
|------|------|
| `ops` | LSM模块的钩子函数集合 |


**返回值**: 无

**备注**: ops参数必须与调用security_add_external_ops接口时的ops参数值相同，否则删除操作会失
败
6.13秘钥管理
基于开源libkeyutils 提供了一套 API，用于创建、查找、更新和删除密钥。
头文件： /usr/include/keyutils.h
开发库： libkeyutils-dev
运行库： libkeyutils1
6.13.1 进程密钥管理

---


> 📌 添加秘钥
> **子模块**: 进程秘钥管理 | **接口类型**: C

**原型**:
```c
key_serial_t add_key(const char *type,const char *description,const void *payload,size_t
plen,key_serial_t ringid);
```

**描述**: 添加进程秘钥

**参数**:

| 参数 | 说明 |
|------|------|
| `type` | 秘钥类型，如： |
| `"process"表示进程秘钥` | description |
| `对密钥的描述信息。用于描述密钥的内容或用途` | payload |
| `密钥中的有效负载数据` | plen |
| `密钥中的有效负载数据长度` | ringid |
| `要将密钥添加到的密钥环的ID：` | KEY_SPEC_PROCESS_KEYRING，则密钥将添加到当前进程的密钥环 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `大于0` | 成功，返回新创建的密钥的序列号(key_serial_t） 小于0 失败 |


**备注**: 无

---


> 📌 查询秘钥
> **子模块**: 进程秘钥管理 | **接口类型**: C

**原型**:
```c
long keyctl_search(key_serial_t ringid,const char *type,const char
*description,key_serial_t destringid);
```

**描述**: 根据类型和描述查询秘钥ID

**参数**:

| 参数 | 说明 |
|------|------|
| `ringid` | 秘钥所在的密钥环ID： |
| `KEY_SPEC_PROCESS_KEYRING，表示当前进程的密钥环ID` | type |
| `秘钥类型：添加密钥时指定的秘钥类型，` | description |
| `密钥的描述信息。添加秘钥时指定的秘钥描述` | destringid |
| `可选，进一步限定密钥环的ID，不指定填0` | - |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `大于0` | 成功，返回密钥的序列号 小于0 失败 |

> 📌 更新秘钥

**参数**:

| 参数 | 说明 |
|------|------|
| `id` | 要更新的密钥的序列号。该序列号是通过其他密钥管理函数（如 keyctl_search 或 |
| `add_key）获得的` | payload |
| `指向新内容的指针。这个内容将替换密钥的现有负载` | plen |
| `新秘钥的长度` | - |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `等于0` | - |
| `成功` | 小于0 失败 |


**备注**: 无

| `大于等于0` | - |
