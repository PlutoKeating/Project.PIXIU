# 6.10.1 OpenSSL国密接口

头文件：openssl/sm2.h
开发依赖包：libssl-dev
运行依赖包：libssl1.1

> 📌 sm2接口说明
> **子模块**: 密码设施 | **接口类型**: C

**原型**:
```c
int sm2_compute_z_digest(uint8_t *out, const EVP_MD *digest, const uint8_t *id, const
size_t id_len, const EC_KEY *key);
```

**描述**: 计算z值

**参数**:

| 参数 | 说明 |
|------|------|
| `out` | 输出参数，输出z值 |
| `digest` | 摘要算法 |
| `id_len` | id长度； |
| `key` | 公钥； |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `成功返回1；失败返回0` | - |
