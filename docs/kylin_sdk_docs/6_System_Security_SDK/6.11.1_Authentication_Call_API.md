# 6.11.1 认证调用接口


> 📌 头文件 security/pam_appl.h, security/pam_misc.h 开发依赖包:libpam0g-dev 运行依赖包:libpam0g
> **子模块**: 认证管理 | **接口类型**: C

**原型**:
```c
int pam_start(const char service_name, const char user, const struct pam_conv
pam_conversation, pam_handle_t *pamh)
```

**描述**: 初始化pam认证

**参数**:

| 参数 | 说明 |
|------|------|
| `service_name` | [in] 为发起pam认证的程序名。认证时会从/etc/pam.d/service_name文件 |
| `获取认证程序的pam配置；` | user |
| `[in] 为发起pam认证的用户，若设为NULL，认证过程中会询问用户输入` | pam_conversation |
| `[in] 指向pam认证过程中使用的对话相关的结构体` | pamh |
| `[in] 为pam认证相关结构体。其内部结构对程序开发者透明，开发者可调用` | pam_set_item, pam_get_item等接口配置认证过程中的相关信息 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `成功时返回PAM_SUCCESS;` | 失败时返回PAM_ABORT, PAM_BUF_ERR, PAM_SYSTEM_ERR |

> **子模块**: 认证管理 | **接口类型**: C

**原型**:
```c
int pam_authenticate(pam_handle_t *pamh, int flags)
```

**描述**: pam身份认证

**参数**:

| 参数 | 说明 |
|------|------|
| `pamh` | [in]pamh为pam_start初始化成功的认证相关结构体 |
| `flag` | [in] flags 为认证标记变量。若无特殊认证流程可配置为0 |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `认证成功时返回PAM_SUCCESS` | 认证失败时返回PAM_AUTH_ERR, PAM_ABORT, PAM_CRED_INSUFFICIENT, PAM_AUTHINFO_UNAVAIL, PAM_MAXTRIES, PAM_USER_UNKNOWN等 |
