> 📌 设置防卸载黑白名单开关标识(自1.2.0.9-0k3.0版本启用)
> **子模块**: 应用防卸载管控 | **接口类型**: dbus

**原型**:
```c
int SetMode(int mode)
```

**描述**: 设置防卸载黑白名单开关标识

**参数**:

| 参数 | 说明 |
|------|------|
| `mode` | 模式（0：不开启黑白名单，1：开启白名单，2：开启黑名单，其它值非法） |


**返回值**:

| 返回值 | 说明 |
|--------|------|
| `0` | - |
| `成功` | -5000 门禁管控禁止访问 其他 失败 |
