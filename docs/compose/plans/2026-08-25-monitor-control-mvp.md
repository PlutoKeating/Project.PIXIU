# 监控掌控层 MVP（批次①）Implementation Plan

> 保留原文件路径与实际章节标题用于引用；正文按唯一宿主实现更新，不保留重建旧前端的代码步骤或旧测试完成数字。
> 当前完整计划为 docs/UNIFIED_FRONTEND_PLAN.md，公共契约为 docs/API.md。

目标是让用户在唯一 Agent 宿主中明确授权、暂停并核对采集。正式实现为
frontend/management/PrivacyPage，业务配置只由后端持久化；目录浏览、配置草稿、
日志和退出保护不构成另一个产品或后台采集器。

## Global Constraints

- 按 ADR-0006 维护唯一宿主；第三方 submodule 不直接修改，必要接入使用导出补丁。
- 前端通过公共 HTTP/WS 契约工作，不访问后端数据库，不建立第二份监控配置。
- 后台组件启动不等于授权开启。没有已保存配置时总闸、四来源关闭，目录为空。
- 保留用户数据、设备身份和会话；源码清退不删除用户 QSettings 文件。
- 中文源文案使用 Qt 翻译机制；官方 Qt 控件翻译与自有产品完整英文资源分别验证。
- 组件回归、OFF 宿主编译、ON 原生安装和真实桌面结果分别记录。
- 每个逻辑变更独立提交，推送和生产发布遵守当前用户授权，不强制推送。

### Task 1: AppSettings 键位扩展 + MonitorController

本章标题保留，不再要求扩展旧键位或创建旧控制器。MonitorController 和专属
回归已删除，无调用者的监控键常量一并移除；AppSettings 的其他使用者保留，
现有用户配置文件不清除，也不把其中旧的授权镜像自动写回后端。

正式配置状态来自 GET /monitor/config。页面成功读取完整形状后才允许编辑保存；
PUT 全量提交时保留剪贴板和截图字段，失败保留草稿。配置保存成功仅证明持久化，
不保证 watcher 已应用或所有在途采集已取消。

有效回归位于 frontend/tests/t_memory_workspace.cpp：
配置读取前门控、来源字段保留、非法目录、保存失败、草稿保护和目录选择期间退出保护。
后端配置持久化与 API 测试独立保留，不以旧 QSettings 测试代替它们。

### Task 2: MonitorCenterDialog 监控中心面板

旧双 Tab 对话框及其专属测试、翻译已删除，正式入口是同一工作区的“采集与隐私”。
旧面板中有价值的目录浏览、时间与关联 ID 已迁入正式页。

- 目录通过宿主既有 KylinFileDialog 浏览，选择只追加草稿，取消不改草稿。
- 不可表示路径被拒绝，重复目录不重复添加，必须显式保存，不自动开启采集。
- 日志按后端倒序分页，显示 UTC、来源、状态、摘要及证据/知识 ID。
- 缺失时间或 ID 明确标示，不推测填充；用户可右键或 Ctrl+C 主动复制。
- 不混合本地开关日志与 WS 帧冒充权威历史，不显示“离线仅本地生效”。
- 剪贴板和自动截图明确未实现，OCR 与行为采集须按实际平台能力核对。

目录选择、取消和不保存授权已有原生实测；日志失焦选中态已在浅色主题复验。
文件选择器翻译和文件视图主题补丁仍需在对应原生安装版本验收，不能据此宣称
所有主题、语言、权限、OCR 或长文本通过。

### Task 3: 入口接线（托盘/悬浮球暂停 + 设置入口 + 状态徽标）

本章不再指导恢复旧托盘、悬浮球、聊天输入栏或 PixiuApp。正式导航为唯一宿主
“设置 → 采集与隐私”，关闭总闸后显式保存暂停请求；保存与实际运行状态分开表达。

BackendEventStatus 接收 capture_event 及重连通知，标记日志需要重新读取；
页面可见、空闲且在首页时合并刷新，历史页不强制跳转，配置草稿不被日志刷新覆盖。
HostCloseGuard 阻止在途操作退出并保护未保存草稿，确认放弃不隐式保存。

旧本地“曾启用”标记、悬浮球角标和三处自动提交链不迁入；正式托盘、快捷键与
通知适配属于唯一宿主，不能随旧控制器一并删除。

### Task 4: 跨模块 API 契约需求单

frontend/docs/MONITOR_API_REQUIREMENTS.md 是当前接口消费说明，不是待实施 API 草图。
详细字段、错误和限制以 docs/API.md 为准：

- GET /monitor/config 返回持久化配置，不是采集器健康证明。
- PUT /monitor/config 全量覆盖；未实现来源的字段由客户端保留，不能冒充功能。
- GET /monitor/log 返回 events，默认 limit=100、最大 500，正式页每页 50 条。
- capture_event 只通知数据变化；无事件重放游标，offset 分页不是稳定快照。
- summary 可能含私人文件名；sensitive_quarantined 仍可能已入库，不代表物理隔离。
- 目录监视非递归，不保证停机文件变化补扫；文本直读与图片 OCR 分别验收。

### Task 5: i18n 收尾与全量验证

删除旧控制器/旧面板专属翻译，不重新生成旧产品可执行文件。唯一宿主通过补丁
0026 按系统语言加载官方 qtbase 翻译，三个发布画像声明 qttranslations5-l10n；
这不是自有产品全部英文文案已经完成的证明。

验证入口为正式管理 CMake、保留回归 CMake 和 build/release 的宿主适配、
画像及色板检查。原生流水线验证完整安装和 SDK 生命周期，真实桌面另核对目录
取消/选择、授权不变、日志显示/复制、主题/语言和退出保护。截图只取真实像素，
不将离屏测试或旧产品画面用作交付素材。

## Self-Review 结论

清退边界是旧监控中心、旧本地配置控制器及其无正式调用的专属内容。
HTTP/WS 公共通信、后端配置与采集实现、正式 PrivacyPage 及管理回归均保留。
不删除用户配置或记忆，不恢复第二套前端。

未完成验收仍包括原生文件对话框语言/主题、完整采集权限与停止竞态、OCR/行为
实际能力以及最终生产包和完整真实图库；不以没有 TODO 或测试数量宣称交付完成。
