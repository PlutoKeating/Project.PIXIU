# PIXIU 唯一桌面前端开发与交付计划

## 目标与执行约束

用户已批准以现有 openKylin Agent 为唯一桌面宿主，将小窗口中有价值的管理能力迁入同一应用，移除独立小窗口实现。架构决定见 [ADR-0006](decisions/0006-unify-agent-desktop-frontend.md)。任务编号仅用于引用，不代表优先级或时间安排。

完成状态必须由代码、构建产物、测试及真实界面共同证明；计划存在不代表实现完成。官方赛题原件保持只读。保留各既有文档的目录及章节结构，修改事实而不重排原文结构。用户数据库、设备身份、配置和会话历史不得作为旧前端残留删除。

## 代码基线与已知差距

- 本计划的审查基线为 `18561766970f6a330be54e3c6f9838076259473d`，产品版本 `0.1.8`。
- `frontend/CMakeLists.txt` 构建独立 `pixiu-frontend`；`PixiuApp` 创建聊天、悬浮球、托盘与管理窗口。
- `build/release/debian/usr/bin/pixiu` 在严格包启动 `kylin-agent`，通用包仍回退旧前端。
- Agent 构建使用固定 submodule 的导出副本及自有补丁；上游记忆设置源码被现有构建补丁排除，不能算已交付界面。
- 旧查询入口仅调用记忆检索，不具备 Agent 循环。管理能力与真正 Agent 会话分离。
- Agent 当前必需 `kysdk-qtwidgets`，删除通用回退前必须使同一宿主支持无 SDK 构建。
- 当前升级辅助脚本位于 `frontend/scripts/`，被统一包消费，不属于可以随旧聊天删除的代码。

### U02：唯一应用外壳与原生管理模块

- [ ] 保留现有 Agent 会话、模型、工具过程、停止、历史及富文本显示。
- [ ] 在同一主窗口提供会话、记忆、设备、设置导航，恢复导航时不销毁进行中的会话。
- [ ] 将自有管理界面维护为可直接编译测试的 Qt 源码模块；宿主补丁仅负责接入，不复制整套管理实现。
- [ ] 统一退出、窗口激活、托盘和单实例行为；管理对话框属于唯一应用，不启动第二个进程。
- 验收：从安装入口进入同一应用即可访问全部管理功能，进程与安装文件中不存在独立小窗口产品。

### U03：公共通信与状态处理

- [ ] 复用并修正异步 HTTP、请求关联、超时、取消、错误解析与过期响应抑制。
- [ ] 从实际配置取得后端地址，核对版本及能力；管理功能不依赖模型或 Runtime 在线。
- [ ] 接入事件刷新与断线重连，区分事件通知和操作请求，禁止把执行完成事件再次当作删除授权。
- [ ] 不直接导入后端私有实现，不建立第二份业务数据真相源。
- 验收：离线、恢复、并发和迟到响应不会覆盖错误对象或误报操作成功。

### U04：记忆检索、录入与更新

- [ ] 建立检索、结果、空态、失败重试与手动录入界面，保留失败输入。
- [ ] 明确个人与共享范围、敏感信息约束和异步入库状态。
- [ ] 基于当前公共更新契约提供版本校验和幂等处理，冲突时提示刷新而非覆盖。
- 验收：真实后端中写入、检索、更新及版本冲突均有界面和测试证据。

### U05：证据阅读与回溯

- [ ] 从记忆结果及 Agent 相关展示进入统一证据详情。
- [ ] 正文优先，单独展示来源、范围、置信度、版本或时间等实际返回的元数据；原始数据仅作为可展开诊断信息。
- [ ] 处理缺失证据、长文、敏感内容与载入失败，不以内部 ID 作为用户理解入口。
- 验收：来源入口可到达真实证据，正文可读、可选择且没有布局截断。

### U06：偏好与冲突审计

- [ ] 迁入偏好列表、提取、历史版本与刷新，避免要求用户手填内部 ID。
- [ ] 展示冲突双方、严重程度与后端实际处理结果。
- [ ] 不提供后端尚无契约的人工裁决或回滚按钮；发现契约缺口时明确记录。
- 验收：列表、详情、历史、空态与错误态对应真实返回数据。

### U07：安全遗忘

- [ ] 统一显式遗忘入口和 Agent 相关确认体验，移除旧聊天前缀意图分流。
- [ ] 展示实际预览目标、影响范围与级联信息，支持取消并阻止重复提交。
- [ ] 不把模型输出当成人类确认；明确当前后端遗忘范围与软删除、墓碑语义，不宣称物理擦除。
- [ ] 验证预览变更、过期响应、执行失败和成功后刷新；必要契约变更按模块单独实现测试。
- 验收：取消不修改数据，确认只执行预期操作，完成事件不会触发第二次执行。

### U08：设备、配对与同步

- [ ] 迁入发现、配对、信任设备、状态、暂停与撤销信任。
- [ ] 核查配对请求的真实双端行为，不把本地事件或本地请求记录当作远端批准。
- [ ] 覆盖拒绝、过期、离线、恢复、无设备、撤销失败与退出网络确认。
- [ ] 展示共享范围及降级信息，不在公开截图暴露实际私有地址或令牌。
- 验收：真实设备与隔离测试分别证明交互和状态一致性；未验证项目不得标完成。

### U09：采集与隐私控制

- [ ] 迁入采集总开关、有效来源、目录管理、日志、暂停与敏感提示。
- [ ] 对照实际采集实现显示能力；剪贴板、截图、OCR 等缺失能力明确不可用，不用配置字段冒充实现。
- [ ] 保留有效配置，不因页面初始化覆盖用户状态；展示保存失败及实际生效状态。
- 验收：修改配置能改变真实采集行为，禁用或不可用来源不会显示虚假成功。

### U10：洞察与摘要

- [ ] 在唯一应用中接入已有洞察与摘要，支持空态、刷新及错误处理。
- [ ] 准确呈现现有规则聚合能力，不能将它包装成未实现的模型推理。
- 验收：界面内容可回溯至真实后端结果，不使用演示桩作为发布证据。

### U11：统一视觉与桌面行为

- [ ] 统一主题、图标、语言、焦点、快捷键、通知与托盘，移除第二份应用设置状态。
- [ ] 检查小屏幕、缩放、长文本、深浅主题、键盘访问和错误文案可读性。
- [ ] 保留有价值的暂停和事件提示，不保留独立悬浮球应用。
- 验收：各导航页属于同一视觉体系；通知与快捷键只注册一次，状态一致。

### U12：安全升级与用户数据迁移

- [ ] 迁入检查更新、下载、完整性及签名校验、系统授权、安装反馈和受控重启。
- [ ] 将产品级安装与重启辅助脚本从旧前端归属中解耦，更新所有打包和测试引用。
- [ ] 核查新进程退出和 Runtime 生命周期，保留现有备份、健康判定、回滚与错误区分。
- [ ] 明确旧设置向唯一应用的映射，保留用户数据、设备身份和 Agent 历史。
- 验收：成功升级与故障注入均通过；取消授权、无效签名和回滚失败不会误报成功。

## 执行依赖与完成审计

唯一宿主接入和公共通信支撑各管理任务；通用宿主适配及管理功能验证是删除旧应用的前提。升级迁移与包体变更必须共同验证。截图与交付说明基于已运行的最终界面，而不是规划中的页面。

完成审计须对 U01—U16 的每个未勾选项提供实际证据并更新状态。构建成功不能代替运行，模拟测试不能代替原生验证，绿色 CI 不能代替安装包唯一入口检查，计划或 ADR 已提交不能代替实现完成。
