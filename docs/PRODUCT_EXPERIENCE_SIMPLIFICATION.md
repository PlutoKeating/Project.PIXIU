# 日常产品体验简化计划

2026-09-10，按用户截图和最新要求执行。保持已迁移的源码目录，不新增独立前端或重复服务。

## 日常主链路

打开即会话 → 描述目标或添加资料 → 必要时审批计划 → 助手执行并报告 → 需要时查看记忆或修正结果。
目录整理、偏好提取、索引更新、页面读取和更新由系统处理。技术状态不占据正常使用的主界面。

## 控件与真实服务对应

| 当前问题 | 调整 | 服务事实与执行边界 |
|---|---|---|
| 顶部常驻连接/健康免责说明与刷新清单 | 正常状态不显示；故障只说明对任务的影响，自动重连；主动报告保留 | BackendEventStatus 已接 WebSocket；事件继续驱动页面更新，不把连接成功当作业务成功 |
| “清除提示”成为日常操作 | 普通状态不产生待清理提示；完成报告自动收起 | 不影响真实任务与结果 |
| 设置同时出现在标题栏和一级导航 | 保留一级设置入口 | 都指向同一宿主设置页，无需重复 |
| 会话来源常驻所有页面 | 只在会话页面提供 | AgentEvidenceClient 已按当前会话读取实际记忆引用 |
| 记忆页有五组技术分类 | 日常只展示资料、简报、偏好；遗忘与会话记录从次级管理入口进入 | 遗忘仍重新预览并审批；阶段记录的保留能力继续可访问 |
| 偏好页要求手动提取 | 删除按钮、前端触发分支和证据传递接口 | `/memory/write` 已执行 preference.extract；会话与 dreaming 沿该链路自动处理 |
| 每页要求点击刷新 | 页面显示时自动读取，相关事件合并更新；失败保留明确重试方式 | 现有定时合并与请求互斥可复用，不能覆盖编辑草稿 |
| 偏好范围与“其他范围”同时铺开 | 使用紧凑的可选过滤，默认展示全部可读偏好 | 查询过滤不是授权，也不能扩大共享权限 |
| 无冲突时仍展示“处理所选冲突” | 只有选中待确认冲突时出现 | 自动裁决仍由后端完成；有歧义的实质决定保留审批 |
| 技术词汇直接成为导航和说明 | 使用“资料”“简报”“偏好”“会话记录”等任务语言 | 不把审计、scope、证据 ID、短期/阶段层级作为普通用户必学概念 |
