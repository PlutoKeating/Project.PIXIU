# 日常产品体验简化计划

## 日常主链路

打开即会话 → 描述目标或添加资料 → 必要时审批计划 → 助手执行并报告 → 需要时查看记忆或修正结果。
目录整理、偏好提取、索引更新、页面读取和更新由系统处理。技术状态不占据正常使用的主界面。

## 控件与真实服务对应

| 当前问题 | 调整 | 服务事实与执行边界 |
|---|---|---|
| 顶部常驻连接/健康免责说明与刷新清单 | 正常状态不显示；故障只说明对任务的影响，自动重连；主动报告保留 | BackendEventStatus 已接 WebSocket；事件继续驱动页面更新，不把连接成功当作业务成功 |
| “清除提示”成为日常操作 | 普通状态不产生待清理提示；完成报告自动收起 | 不影响真实任务与结果 |
| 设置同时出现在标题栏和一级导航 | 保留一级设置入口 | 都指向同一宿主设置页，无需重复 |
| 会话来源按钮无日常操作价值 | 删除标题栏按钮、请求与切页处理 | 后台实际记忆引用记录保留；资料检索原文阅读继续可用 |
| 记忆页有五组技术分类 | 日常只展示资料、简报、偏好；遗忘与会话记录从次级管理入口进入 | 遗忘仍重新预览并审批；阶段记录的保留能力继续可访问 |
| 偏好页要求手动提取 | 删除按钮、前端触发分支和证据传递接口 | `/memory/write` 已执行 preference.extract；会话与 dreaming 沿该链路自动处理 |
| 每页要求点击刷新 | 页面显示时自动读取，相关事件合并更新；失败保留明确重试方式 | 现有定时合并与请求互斥可复用，不能覆盖编辑草稿 |
| 偏好范围与“其他范围”同时铺开 | 使用紧凑的可选过滤，默认展示全部可读偏好 | 查询过滤不是授权，也不能扩大共享权限 |
| 无冲突时仍展示“处理所选冲突” | 只有选中待确认冲突时出现 | 自动裁决仍由后端完成；有歧义的实质决定保留审批 |
| 技术词汇直接成为导航和说明 | 使用“资料”“简报”“偏好”“会话记录”等任务语言 | 不把审计、scope、证据 ID、短期/阶段层级作为普通用户必学概念 |

## 视觉与布局规范

使用 ui-ux-pro-max 技能检索后，按原生 Qt 桌面场景筛选建议，不采用检索结果中的营销页结构、紫粉配色或在线字体依赖。参考 [Linear 的界面整理说明](https://linear.app/now/behind-the-latest-design-refresh) 的视觉权重与弱化边界，以及 [KDE 布局规范](https://develop.kde.org/hig/layout_and_nav/) 的分组间距、上下文操作和窗口适配原则。

- 标题栏合并品牌与会话、记忆、设备、设置四个入口，取消重复的一级标签行。程序内部切换页面同步选中入口；会话侧栏固定显示，删除折叠按钮及槽函数。
- 记忆与设置的内容分类置于 160 px 左侧栏，横向文字和选中底色提供定位，取消二级顶部标签。主导航使用系统高亮色；支持系统调色板，不额外提供配色选项。
- 资料页以 22 pt 标题、32 px 水平留白、16 px 内容间距和 42 px 搜索输入区建立层级。资料范围与手动记录归入次级菜单，常用路径仍是会话和搜索。
- 未搜索时不显示空白结果与证据面板。偏好列表无记录时收起，详情只在有内容时出现。已有资料结果、编辑、遗忘审批与原文阅读继续使用现有服务。
- 当前这批只完成导航与资料页面的骨架整理；设置表单、简报阅读版式与真实会话内容的整体视觉验收仍需继续，不能据此宣称全产品视觉改版完成。
