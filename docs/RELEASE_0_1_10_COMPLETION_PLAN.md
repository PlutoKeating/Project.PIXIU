## 当前实现

- 文档：复用 Kreuzberg/PDFium、Pillow、openpyxl，无需目标机器安装 LibreOffice；OCR 不参与知识提取。所有 PDF 页保留渲染图像，Word/PPT 图表保留 XML 系列、分类与缓存值，不执行公式和外链。复杂绘图不能据此宣称完整支持。
- 长附件：超过两个块时保留既有 24 小时文档引用，pixiu_document_read 按 document_id/version/cursor 读取；图片块复用 Runtime 多模态工具结果并复核当前模型能力。未读取全文不得声称全部理解；三个文本块的真实模型读取已验证，更大容量和图像仍待验证。
- Dreaming：schema 15 的 dreaming_plans 保存计划；模型先读取目标并冻结版本，更正与合并须进入审批。桌面展示原记录与建议，批准后执行；合并旧记录退出有效检索，来源保留。MCP 不提供批准入口。
- 来源：回答链接绑定已消费的上下文和实际知识条目，读取时重查授权、有效状态与敏感级别。宿主补丁 0030 打开 CitationDialog，展示原文和原图；不恢复全局来源按钮。
- 打包：源码快照审计复用固定上游版本和逐文件摘要检查；版本清单使用迁移后的 VERSION 路径，支持无 .git 的交付源码。无新增依赖或源码目录。
