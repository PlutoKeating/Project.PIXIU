# PIXIU 操作截图与复现记录

本次已整理 38 张银河麒麟 V11 实拍，覆盖安装启动、助手记忆、编辑、遗忘、采集、偏好、设备入口和设置。每张均已实际打开检查。停止后的状态显示存在问题，设备联机与升级回滚等场景仍待补齐，详见文末。

## 版本与环境

截图来自安装包 `pixiu_0.1.9-1_amd64.deb`，构建提交 `1c4a858b224f93da16936e37d6028fc6c058eb9c`。软件包摘要及 Ed25519 发布签名验证通过；运行主程序与安装文件的 SHA-256 一致。桌面和后端为 0.1.9，HTTP API 为 0.5.0，数据库为 13，Embedding 与 Vector Engine 均实际使用麒麟 SDK。构建提交之后的产品代码没有变化，本次修改交付材料与导出工具。

环境为 1440 × 900 的 V11 Wayland 桌面。图片通过 `virsh screenshot` 读取实际桌面帧，保留系统维护模式水印和实际警告。画面没有重绘、拼接或替换文字。完整摘要、采集时间和运行核对结果见[截图清单](截图清单.json)，可在[图片画廊](图片画廊.html)逐张打开原图。

## 演示数据与恢复

账单使用公开合成数据：电费 210 元、水费 68.50 元、燃气费 156 元，合计 434.50 元。助手保存的账单与手动录入的账单是不同记录。手动编辑将燃气费改为 186 元、合计改为 464.50 元，不能据此要求先前助手记录同步变化。

偏好、长正文和遗忘示例使用独立范围 `user:pixiu-screenshots`。遗忘只确认本次创建的临时便笺。其他演示记忆保留用于复现，没有清空用户数据。版本冲突通过公共 API 对同一演示条目制造并发更新，截图记录真实拒绝结果，没有直接改写数据库。

目录采集仅指定 `/var/tmp/PIXIU操作演示`，保存开关后创建公开文本文件并核对入库日志。安装演示完成同版本重装。采集配置已逐字段恢复为操作前的配置，主题恢复浅色；最终核对主程序只有一个实例，三个后台服务均运行。

## 尚未完成的场景

多设备的双向配对、传输暂停和恢复、信任撤销及删除传播还需可互通的独立设备实测。本次设备图只显示单机状态和配对入口。

本次更新检查返回“已是最新版本”。图形安装器、新版本安装授权、重启事务和失败回滚尚无完整实拍。当前系统的 `.deb` 默认打开程序为归档管理器，手册提供本次已验证的终端安装方法。

工具授权、会话错误、冲突审计双方、遗忘预览过期与版本变化，以及 125%/150% 缩放矩阵仍待采集。目录采集图不涵盖尚未实现的剪贴板与自动截图功能。

停止任务已核对后台工具结果：`sleep 45` 返回 `[Command interrupted]`，退出码为 130。界面仍同时显示“已完成工作”和“进行中”，S10 记录此问题，不能用于宣称停止状态显示正确。最终版本需修复并重新采集。
