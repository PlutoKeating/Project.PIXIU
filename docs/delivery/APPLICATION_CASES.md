## 目录里的资料，成为助手可用的知识

0.1.12 在银河麒麟 V11 上重新录制了目录监控与 Dreaming 场景。用户在“采集与隐私”中授权演示目录、启用目录采集并保存，将“星河观测活动安排”文件放入目录。主窗口显示后台整理进度，活动日志随后显示该文件已整理并保存 1 条记忆。

## 三设备重连后补齐更新

0.1.12 正式包在同一宿主的三台独立 V11 虚拟机上完成验证：

1. 三端配对，自动同步一条资料移交记忆。
2. 暂时隔离同步，两端分别更正时间和地点，第三端保留原记录。
3. 恢复同步，约 30.5 秒后三端正文、版本、来源和同步状态一致。

可信设备各自保存副本，用户可以继续使用本机资料，联网后自动接收更新。

## 用户价值

| 场景 | 带来的帮助 |
|---|---|
| 新会话查询 | 复用过去保存的资料 |
| 核对信息 | 从回答直接查看来源 |
| 更正资料 | 审批建议并保留版本记录 |
| 多设备工作 | 自动同步共享资料与更正 |
| 管理隐私 | 按授权范围使用资料，确认后遗忘 |
