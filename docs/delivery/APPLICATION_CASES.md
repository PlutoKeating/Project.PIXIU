# 应用案例

## 活动资料整理与更正

本例在银河麒麟 V11 上使用 PIXIU 0.1.12，演示从活动通知到跨会话查询的完整过程。用户授权资料目录、启用采集并保存设置，再放入“星河观测活动安排”。主窗口显示整理进度，活动日志记录已保存 1 条记忆。

打开新会话，询问活动集合时间、地点和器材预算，助手从长期记忆中找回：2026 年 11 月 8 日晚七点、社区天文台三层、2680 元。点击回答中的来源链接，打开原文，核对活动安排和器材归还流程。

这条路径适用于活动安排、会议资料和工作步骤：用户照常保存文件，后台负责整理，后续任务直接调用已保存的知识。

用户随后将更新通知放入同一目录：活动改为 11 月 15 日晚七点半，地点改为社区天文台二层，预算仍为 2680 元。Dreaming 提出更正方案，用户在桌面核对新旧内容后点击“批准更正”，系统保存新版本。

## 三设备重连后补齐更新

0.1.12 正式包在同一宿主的三台独立 V11 虚拟机上完成验证：

1. 三端配对，自动同步一条资料移交记忆。
2. 暂时隔离同步，两端分别更正时间和地点，第三端保留原记录。
3. 恢复同步，约 30.5 秒后三端正文、版本、来源和同步状态一致。

可信设备各自保存副本，用户可以继续使用本机资料，联网后自动接收更新。

## 用户价值

| 场景 | 带来的帮助 |
|---|---|
| 新会话查询 | 复用过去保存的资料 |
| 核对信息 | 从回答直接查看来源 |
| 更正资料 | 审批建议并保留版本记录 |
| 多设备工作 | 自动同步共享资料与更正 |
| 管理隐私 | 按授权范围使用资料，确认后遗忘 |
