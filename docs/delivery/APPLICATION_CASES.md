# D-09 实际应用案例工作稿

- 更新日期：2026-09-03

## 案例一：家庭支出跨文档聚合

用户在设备 A 导入多张水、电、燃气清单；PIXIU 保留 OCR/手动来源并结构化金额、
月份和类别。用户在 Agent 中以模糊自然语言询问总支出，Agent 自主召回相关记忆，
聚合结果并展示每张清单的 evidence。随后用户要求忘记某月清单，系统二次确认并
验证该证据及关联结果不再被召回。

## 案例二：多设备工作流复用

设备 A 的 Agent 通过 Shell/联网搜索完成一个需要审批的任务，PIXIU 把有价值的工具
结果和工作流沉淀为长期记忆。设备 B 离线期间并发更新相关偏好，设备 C 删除敏感
条目；三机重连后经 Gossip/反熵与 CRDT 收敛。新会话中的 Agent 自主复用最终工作流，
同时遵守偏好、冲突裁决和遗忘墓碑。

## 最终证据要求

每个步骤保存 Agent run、tool-call、审批、memory/evidence ID、设备 ID、断网区间、
收敛摘要、截图和视频时间戳。案例一对应附录 A，案例二体现团队分布式亮点；两者
必须运行在同一最终 V11 双 SDK 候选版本，不用 stub 或固定脚本假扮自主决策。
