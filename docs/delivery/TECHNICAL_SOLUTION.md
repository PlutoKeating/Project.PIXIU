# PIXIU 技术方案

## 作品概述

PIXIU 帮助银河麒麟 V11 上的智能助手保存和复用长期记忆。用户可以查找过去的对话和工具结果，查看信息来源，更新已保存的知识，并让可信设备共享所需内容。

系统接收对话、工具结果、用户行为、手动配置和文档。文本与 Office 资料由包内组件解码；图片及扫描 PDF 由具备多模态能力的当前模型处理。OCR 用于敏感内容定位与标注。

## 解决的问题

跨会话和跨设备工作需要保留任务经验。例如，用户换一台电脑整理家庭账单时，需要找到原来的支出清单、沿用输出偏好，并确认金额来自哪条记录。

PIXIU 分别保存原始证据、知识、偏好和冲突记录。每条记录带有来源、使用范围、版本和敏感程度，便于检索、更新和追溯。

## 总体架构

用户在一个 PIXIU 主窗口中完成会话、记忆管理、设备管理和设置。桌面端基于 openKylin KylinAgent，agent-runtime 负责规划任务、调用工具和请求用户审批。

PIXIU 通过 MemoryProvider 接口为助手提供记忆读写能力。该适配层调用公共 API；后端负责数据接入、偏好提取、知识管理、检索、同步和遗忘。

后端按职责组织模块：记忆引擎处理接入、偏好、知识和安全；基础服务管理存储、检索、记忆流转及评测；同步模块负责设备间的更新；平台适配层调用系统 SDK。

## 记忆写入

系统先校验输入格式、整理字段、评估质量并检查敏感信息，再保存原始证据（evidence）。随后提取知识和偏好，建立实体关系及检索索引，并处理与已有知识的冲突。

助手产生的记忆保留会话、任务、轮次、工具调用、审批和时间信息。后端保存写入请求的处理结果，重复请求可复用已完成的结果。Provider 将待发送记录保存在本地队列中，以便处理发送失败。

## 记忆检索

系统同时按关键词、语义相似度和实体关系查找候选内容。关键词通道使用 BM25 评分；语义通道比较文本向量；关系图通道沿实体关系查找相关知识。

系统用 RRF 方法合并三个通道的排名，再按使用范围和时间筛选结果。对于家庭支出等结构化数据，系统还能汇总金额。结果附带知识和原始证据的引用，用户可据此核对来源。

检索和金额计算由后端执行。银河麒麟 V11 使用系统 Embedding 接口生成文本向量，并通过 Vector Engine SDK 保存、搜索和删除向量。

## 偏好与知识

偏好包括操作习惯、输出风格和安全策略。系统保存提取结果、置信度和版本历史，供后续任务使用。知识包括事实、工作流、案例和模板，并关联支持它们的原始证据。

知识编辑使用版本检查：提交时版本已经变化，系统会拒绝覆盖，用户需要重新读取后再编辑。冲突页面显示新旧内容、处理方式和时间，便于追查变化原因。

## 精准遗忘

用户用自然语言描述要遗忘的内容，界面先列出目标和相关记录数量。用户确认后，系统将目标知识标为已遗忘并移除向量。原始证据、关系和全文索引中的部分数据仍会保留。

每次预览生成一次性确认凭证，绑定目标及其版本。凭证过期或目标发生变化时，用户需要重新预览。共享知识还会生成删除记录（墓碑），用于向可信设备传播删除状态。

## 分布式记忆网络

每台设备保存本地副本，离线时仍可读取和写入。设备通过交换配对令牌建立信任；共享记录进入带签名的操作日志，私人记录保存在本机。系统分别使用 `shared:*` 和 `user:*` 标识这两种使用范围。

CRDT 根据版本信息合并同一条知识的并发更新。Gossip 将新操作传给在线设备；反熵对账在设备重连后比较记录并补齐遗漏。设备间通过双向证书验证身份，使用加密连接传输数据。

## 记忆流转

短期记忆保存当前任务上下文，中期记忆保存会话或项目状态，长期记忆保存可重复使用的事实、偏好和工作经验。

每轮任务开始前，MemoryProvider 按内容长度上限读取相关长期记忆。轮次完成后保存对话和工具结果，压缩、切换或结束会话时保存中期状态。助手可以调用记忆工具查询、记录和更新内容；遗忘执行由用户在界面确认。

## 安全与隐私

写入前，系统检查身份证号、银行卡号和手机号等敏感信息。敏感内容仅限本机使用，并从助手的记忆上下文中排除。敏感检测出错时，系统拒绝该次写入并返回错误。

设备配对、风险工具、遗忘和升级分别请求用户确认。模型密钥由 Runtime 的认证功能保存，用户通过设置界面配置模型服务。

## 平台适配

银河麒麟 V11 构建启用桌面 KylinSDK、Embedding SDK 和 Vector Engine SDK。启动检查确认依赖可用后，后端才进入就绪状态。Debian 兼容构建使用可移植实现，验证结果注明实际运行环境。

一个 `.deb` 包含桌面程序、内嵌管理界面、后端、MemoryProvider、Runtime 离线依赖、许可证和版本清单。后端在当前桌面用户的 systemd 会话中运行，以访问该用户的系统 AI 服务。

## 实现分工

PIXIU 实现记忆引擎、混合检索、记忆流转、分布式同步、MemoryProvider、系统 SDK 适配、管理界面和评测发布工具。KylinAgent 与 agent-runtime 提供会话、规划、工具和审批功能，各上游组件随包记录版本、来源和许可证。

## 应用价值

用户可以在新任务中调用过去的知识和工具结果，减少重复录入；通过来源和版本记录核对内容；在可信设备之间继续工作。家庭账单检索和跨设备工作流是两组具体应用，操作过程见应用案例。
