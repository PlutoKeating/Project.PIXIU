# PIXIU 用户手册

适用版本：0.1.12。平台：银河麒麟桌面操作系统 V11。

## 开始使用

安装后从应用菜单打开 PIXIU。主窗口提供“会话、记忆、设备、设置”四个入口；记忆和设置的分类位于左侧。

## 与助手协作

1. 点击“新建会话”，输入目标；需要处理文件时点击“添加附件”。
2. 助手规划工作并报告进度。出现审批请求时，核对计划后批准。
3. 在回答中查看结果，点击来源链接阅读对应原文。

例如：“记住这份采购清单，下次帮我核对金额。”以后在新会话中直接询问清单内容即可。

## 资料与记忆

在“记忆”中检索资料、阅读来源、查看偏好和简报。需要更正时，可以直接告诉助手新的内容，也可以编辑找到的记忆。

在对话中说明“回答简洁一些”等偏好，助手会保存并在后续任务中使用。偏好页提供当前设置和版本历史。

需要遗忘时，告诉助手具体目标。核对界面列出的内容并确认后，系统隐藏相关知识、清理检索向量，并同步共享记录的遗忘状态。

## 文件与后台整理

聊天附件支持文本、PDF 和常见 Office 文档。系统自动解码并按内容分块交给助手。图片及扫描 PDF 使用当前模型的多模态能力，适用状态显示在设置页。

### 授权目录，让资料自动进入记忆

1. 打开“设置 → 采集与隐私”，点击“添加文件夹”选择用于整理的资料目录。
2. 开启“启用自动采集”和“目录文件变化”，点击“保存设置”。
3. 把资料保存或移入所选目录，也可以编辑其中已有文件。监控覆盖该目录的直接子文件；需要整理子目录时，分别添加对应目录。
4. 主窗口显示后台整理进度。完成后，在采集日志核对文件与保存结果，再到会话中询问资料内容。
5. 点击回答来源，核对资料原文和整理后的知识。

建议先用一份活动安排开始：写明日期、地点、预算和操作流程，保存后询问“读书会什么时候举行，资料预算是多少？”这条路径把日常保存文件与以后查询资料连接起来。

### Dreaming：后台阅读与整理

Dreaming 会分批阅读授权资料，检索已有知识并形成整理方案。新知识保存在个人资料中；对已有记录的更正和合并会显示审批入口。主窗口根据任务状态显示阅读进度、已保存数量和需要处理的计划。

更正资料时，将更新通知放入授权目录。打开待审批计划，对照原内容、建议结果和依据，点击批准。完成后在新会话中再次查询，核对新的日期、地点或金额。合并计划会集中展示参与整理的原记录与最终内容，批准后来源继续保留。

目录资料大小上限为 30 MiB。文字与 Office 内容由安装包内的文档组件读取，图片和扫描 PDF 使用当前模型的多模态能力。设置页显示当前资料读取能力，任务按实际处理结果报告进度。

采集授权由用户管理。关闭自动采集后，已经保存的记忆继续可用。更改目录列表并保存后，服务按新的目录授权处理后续资料。

## 连接设备

在“设备”页添加可信设备，按提示完成配对。在设置中授权助手访问共享空间后，即可跨设备查询共享资料。设备重新联网后会自动补齐更新；私人记忆保存在本机。

助手的读取范围与新记忆的保存位置分别设置。先选择助手可读取的共享空间，再按协作需要设置保存位置。例如，将家庭约定保存到家庭共享空间，在另一台可信设备的新会话中询问相同安排，并点击来源核对。目录整理得到的个人资料由用户选择后用于共享。

设备页提供同步状态、暂停与恢复同步、解除信任等操作。暂停期间继续使用本机副本，恢复同步后接收更新。多端同时修改同条资料时，系统处理版本关系并形成一致记录。

## 阶段记忆、洞察与简报

在记忆页查看当前任务和阶段记录，选择需要长期保留的内容。长期保留后，可在后续会话中检索使用，并查看对应来源。

“洞察与简报”提供近期知识线索与按日期汇总的采集情况。打开洞察可继续检索正文，切换日期可查看当天的资料沉淀记录。

## 个性化设置

| 设置 | 用途 |
|---|---|
| 模型 | 使用麒灵系统云模型，或配置支持的模型服务 |
| 外观 | 切换浅色和深色主题 |
| 界面动效 | 默认开启，可通过一个开关关闭 |
| 快捷键 | 默认 Ctrl+Alt+P 唤起窗口 |
| 采集与隐私 | 管理目录授权和自动采集 |
| 应用更新 | 检查、下载并安装新版本 |

## 软件更新

在设置中点击“检查更新”。系统校验安装包、请求安装授权并检查更新后的服务。保存当前工作后，按提示重启应用即可继续使用。升级恢复机制会保护已有记忆和配置。
