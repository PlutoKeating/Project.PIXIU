## Debian 兼容环境评测

历史数据集 `pixiu-family-expense-v1` 包含 50 组检索、15 组偏好和 25 组冲突用例；检索重复运行 1000 次。运行环境为 Debian portable。

| 指标 | 实测结果 | 目标 |
|---|---:|---:|
| 检索召回率 | 100% | ≥85% |
| 偏好准确率 | 100%（15/15） | ≥85% |
| 冲突处理正确率 | 96%（24/25） | ≥88% |
| 检索 P95 延迟 | 115 ms | ≤500 ms |
