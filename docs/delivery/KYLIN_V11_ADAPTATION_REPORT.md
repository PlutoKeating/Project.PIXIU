# 银河麒麟 V11 适配报告

## 适配结论

0.1.12 正式包已在银河麒麟 V11 amd64 完成安装与启动。系统 Embedding、Vector Engine 和产品记忆写入、查询、遗忘测试通过。三台独立虚拟机完成共享与断连并发更正验证。

## 用户会话架构

系统 AI 服务按桌面用户分开管理连接。PIXIU 后端因此运行在当前用户的 systemd 会话中，使系统向量服务、Agent 运行时和本地记忆都使用同一用户身份。

服务启动时验证运行进程所属用户、本机服务身份、产品版本和数据库状态，确保各组件连接到当前用户的记忆服务。

## Embedding SDK

系统通过 Kylin coreai/embedding 接口把文本转换为 gte-base 模型的 768 维向量。启动时先检查模型、AI 服务、客户端库和 SDK 调用，全部就绪后开始处理业务。

## Vector Engine SDK

向量库通过 ConnectParam(appId) 建立本地应用连接，再用 LoadDBFile 加载该应用的数据库。系统随后执行集合创建、向量写入、搜索和删除，退出时清理资源并断开连接。

启动预检在首条业务写入前验证数据库生命周期。产品接口验证记忆写入、召回、遗忘及检索结果随遗忘更新。

## KylinSDK 与界面

`KYSDK=ON` 构建启用系统快捷键、通知和 Qt 扩展适配。界面按浅色和深色主题设置文字、背景及状态颜色，消息区保持居中阅读宽度，长会话标题省略显示，键盘焦点和操作状态清晰可见。

Debian 兼容构建使用标准 Qt 快捷键和系统托盘通知，用于验证基本桌面功能。麒麟 SDK 功能在 V11 环境单独测试。

## 安装与升级

单一 .deb 包含桌面宿主、管理界面、后端、记忆适配、Runtime 离线依赖和原生扩展。包内同时提供软件物料清单 SBOM 与版权许可证说明 NOTICE，便于核对组件来源。

安装前置脚本校验 V11 与架构；服务启动再次校验双 SDK；用户首次启动校验 Agent 与 Runtime。各阶段检查通过后继续执行。

图形升级先验证安装包摘要和签名，安装后检查软件版本、数据库结构、记忆适配接口和服务状态。检查失败时，自动恢复机制还原原有安装包、配置、数据和服务。

## 安全与可移植性

适配层负责调用平台 SDK。V11 严格配置要求使用原生实现；Debian 兼容配置提供基础写入、检索和测试功能，并记录实际使用的实现。

用户配置文件权限设为 0600，仅所属用户可读写。设备同步采用可信配对、操作签名和双向 TLS 证书验证。敏感记录限于本机受控范围，模型密钥由运行时认证功能保存。
