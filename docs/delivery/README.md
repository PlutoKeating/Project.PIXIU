# PIXIU 交付文档

本目录为四项作品的内部编写源。作品清单与完整要求唯一见 [交付计划 §0](../DELIVERY_PLAN.md#0-赛方交付作品要求唯一权威永久冻结)。分篇内容汇入项目报告或技术方案，不逐篇另交。

最新实物审查见 [2026-09-08 审查记录](DELIVERY_AUDIT_2026-09-08.md)：三类非视频作品
均未就绪，当前文件不可直接作为最终交付。审查记录与配套证据仅供内部整改追踪。

| 文件 | 评委要解决的问题 |
|------|------------------|
| `TECHNICAL_SOLUTION.md` | 作品是什么、如何实现、创新在哪里 |
| `TEST_REPORT.md` | 测了什么、结果如何、证据在哪里 |
| `USER_MANUAL.md` | 用户如何完成核心操作 |
| `MEMORY_LIFECYCLE.md` | 短期、中期、长期记忆如何流转 |
| `APPLICATION_CASES.md` | 作品如何解决真实问题 |
| `KYLIN_V11_ADAPTATION_REPORT.md` | 如何满足 V11 与双 SDK 要求 |
| `DEPLOYMENT_GUIDE.md` | 如何校验、安装、验证、升级和排障 |
| `SOURCE_AND_LICENSES.md` | 哪些是原创、依赖什么、如何复现 |
| `PRESENTATION_AND_VIDEO.md` | PPT 与 5-10 分钟视频如何讲述 |

技术方案须包含用户手册、安装部署指南、操作说明、测试结果及效果验证报告。项目报告须明确记忆流转与适配测试结论。

最终仅提交项目报告、技术方案、功能演示视频、源代码各 1 份。视频为 zip，大小不超过 200M。格式、两层目录命名按冻结记录执行；作品内容一律匿名。
