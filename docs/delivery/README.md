## 文稿维护

正文先说明主要结论，再解释原因、方法和结果。每段围绕一个意思展开，用具体动作和例子说明功能。操作步骤用编号，平行内容或比较项用列表和表格，其余内容写成连贯段落。

面向用户的手册使用实际菜单和按钮名称，说明操作结果及失败后的处理方法。技术方案在首次使用术语时解释其作用，保留理解算法、复现测试和部署所需的细节。删除口号、空泛过渡、自问自答和无关的对照句。

文稿中的实现状态、使用限制和历史测试范围需要准确保留。修改 Markdown 后同步交付分篇和主技术方案，运行文档导出脚本，再逐页查看 PPT、PDF 和 Word。
