# PIXIU 交付文档

本目录是评委材料的唯一 Markdown 来源。每份文档独立回答一个问题，避免重复堆叠工程过程信息。

| 文件 | 评委要解决的问题 |
|------|------------------|
| `TECHNICAL_SOLUTION.md` | 作品是什么、如何实现、创新在哪里 |
| `TEST_REPORT.md` | 测了什么、结果如何、证据在哪里 |
| `USER_MANUAL.md` | 用户如何完成核心操作 |
| `MEMORY_LIFECYCLE.md` | 短期、中期、长期记忆如何流转 |
| `APPLICATION_CASES.md` | 作品如何解决真实问题 |
| `KYLIN_V11_ADAPTATION_REPORT.md` | 如何满足 V11 与双 SDK 要求 |
| `DEPLOYMENT_GUIDE.md` | 如何校验、安装、验证、升级和排障 |
| `SOURCE_AND_LICENSES.md` | 哪些是原创、依赖什么、如何复现 |
| `PRESENTATION_AND_VIDEO.md` | PPT 与 7 分钟视频如何讲述 |

官方赛题原文与官方 PPTX 保持只读。交付文档只引用其要求，不改写权威原件。

对应 PDF 由团队审核 Markdown 后手工导出；Markdown 与 PDF 使用相同文件名并放在同一目录。
