## 项目报告

版本：0.1.12。项目报告为31页可编辑路演稿，按场景需求、服务架构、功能亮点、技术实现、完整案例、商业探索与结束语组织。开场采用根目录 README 的家庭账单背景；完整案例使用同一次真实录制中的活动资料、来源、更正审批与更新查询。人物叙事及演示资料为合成场景，不冒充客户试点。

页面使用蓝色渐变、网络纹样、分层轮廓、架构图、飞轮、流程与时序图，并嵌入原始产品截图。审批前后采用并列关键帧，31页均可静态阅读；连续操作保留在演示视频中。历史 portable 量化数据与当前 V11 原生功能证据分别呈现；商业内容为待验证设想。

## 演示内容

演示顺序以 `submission/video-production/storyboard/shots.json` 为准。目录监控与 Dreaming 展示“文件进入目录 → 后台整理 → 新会话使用 → 来源核对 → 更正审批”；多设备协作展示“配对授权 → 一端记录 → 另一端使用 → 重连补齐”。

账单示例的合计为 434.50 元，已与工具结果、公共 API 和原文核对。视频制作已取得真实跨端检索、同步检查点、偏好版本历史和原生桌面素材。

## 制作要求

| 项目 | 要求 |
|---|---|
| 格式 | 一份 ZIP，5—10 分钟，大小按交付规范控制在 200M 以内 |
| 画面 | 使用真实麒麟桌面，关键操作和来源采用近景 |
| 字幕 | 中文、清晰、与配音同步 |
| 数据 | 指标标注版本、环境和样本量 |
| 匿名 | 使用作品名称和公开合成资料 |

完整作品规则见 `docs/DELIVERY_PLAN.md` 第 0 节。制作过程与素材索引由视频工程维护。
