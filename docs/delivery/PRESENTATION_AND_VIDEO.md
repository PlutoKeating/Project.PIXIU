## 演示内容

演示顺序以 `submission/video-production/storyboard/shots.json` 为准。目录监控与 Dreaming 展示“文件进入目录 → 后台整理 → 新会话使用 → 来源核对 → 更正审批”；多设备协作展示“配对授权 → 一端记录 → 另一端使用 → 重连补齐”。

账单示例的合计为 434.50 元，已与工具结果、公共 API 和原文核对。视频制作已取得真实跨端检索、同步检查点、偏好版本历史和原生桌面素材。

## 制作要求

| 项目 | 要求 |
|---|---|
| 格式 | 一份 ZIP，5—10 分钟，大小按交付规范控制在 200M 以内 |
| 画面 | 使用真实麒麟桌面，关键操作和来源采用近景 |
| 字幕 | 中文、清晰、与配音同步 |
| 数据 | 指标标注版本、环境和样本量 |
| 匿名 | 使用作品名称和公开合成资料 |

完整作品规则见 `docs/DELIVERY_PLAN.md` 第 0 节。制作过程与素材索引由视频工程维护。
