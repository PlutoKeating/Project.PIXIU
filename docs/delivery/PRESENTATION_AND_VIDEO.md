# PIXIU 项目报告与演示说明

## 项目报告

版本：0.1.12。2026-09-19按正式宣传片《演示视频-0.1.12演示增强版》重新撰写，共34页、六个章节。内容依据为499.333秒成片的30个镜头、操作画面与口白，顺序使用 `submission/video-production/src/timeline.json` 的实际帧位置。第2页列出六章名称、子主题和起始页码，点击标题可跳转，后续页面均有返回目录链接。

内容依次呈现日常资料积累、经验维护、可信设备协作、记忆边界、系统协同、效果与价值。场景采用片中496元采购任务、星河观测资料更新、434.50元九月账单、社区图书角和书房—客厅共享安排。视频未展开的商业模式与技术延伸已移除。公开合成演示资料不冒充客户试点。

版式按内容选择：独立章节页、金额与明细、原文与审批对照、版本时间轴、阶段台阶、设备桥接、离线泳道、分层架构与数据大字。页面文字和图形可编辑；产品实拍保持原始图片字节。历史Debian兼容环境量化结果与当前麒麟V11功能验证分开呈现。

生成入口为 `build/release/scripts/build-presentation.py`。版式源、成片60帧核对、全部34页WPS渲染及复核记录见 `submission/presentation-production/`；正式命名目录只接收最终文件。

## 演示内容

正式视频保持不变。当前PPT逐镜对应表见制作工程 `source/video-aligned-plan.md`，每页备注保留所对应镜头的完整口白，页脚给出成片时间范围。视频SHA-256为 `8e870f0f53af841c67926ae3120cb101564aca438c23d81214c65ffee228a89f`，与正式视频ZIP内成员的已核验摘要一致。

设计参考为联网查阅的 [Anthropic PPTX skill](https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md)：应用内容驱动的版式变化、深浅对比、可编辑图形、实际渲染审查和Office文件验证。参考包仅安装于制作目录的忽略运行缓存。

## 制作要求

| 项目 | 要求 |
|---|---|
| 格式 | 一份 ZIP，5—10 分钟，大小按交付规范控制在 200M 以内 |
| 画面 | 使用真实麒麟桌面，关键操作和来源采用近景 |
| 字幕 | 中文、清晰、与配音同步 |
| 数据 | 指标标注版本、环境和样本量 |
| 匿名 | 使用作品名称和公开合成资料 |

完整作品规则见 `docs/DELIVERY_PLAN.md` 第 0 节。制作过程与素材索引由视频工程维护。
