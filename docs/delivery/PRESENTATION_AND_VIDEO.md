# PIXIU 项目报告与演示脚本

## 项目报告结构

1. 赛题痛点：记忆跨会话、跨工具、跨设备复用困难。
2. 作品定位：面向银河麒麟 V11 的 OS Agent 分布式记忆系统。
3. 系统架构：KylinAgent、MemoryProvider、记忆引擎、同步网络、双 SDK。
4. 核心能力：多源接入、偏好与知识、混合检索、流转、遗忘。
5. 核心创新：去中心化全连接记忆网络与墓碑防复活。
6. 平台实现：V11 用户服务、Embedding、Vector Engine、单包交付。
7. 测试结果：自动化回归、原生链路、四项指标与失败分析。
8. 应用价值：家庭支出检索与跨设备工作流复用。
9. 原创边界：团队实现、上游依赖、许可证与可重建证据。

## 7 分钟演示脚本

| 时间 | 画面 | 解说重点 |
|------|------|----------|
| 0:00–0:30 | V11 桌面、关于页 | 作品定位、版本、目标平台 |
| 0:30–1:10 | 安装与服务状态 | 单一 `.deb`、用户服务、双 SDK capability |
| 1:10–2:35 | Agent 多轮任务 | 规划、Shell/搜索、审批、工具结果写入 |
| 2:35–3:30 | 新会话召回 | 长期记忆复用、来源追溯、偏好适配 |
| 3:30–4:15 | 冲突与遗忘 | 版本审计、影响范围、二次确认 |
| 4:15–5:25 | 三设备同步 | 离线写入、并发更新、重连收敛、墓碑 |
| 5:25–6:15 | 测试报告 | 数据集、四项指标、V11 原生结果 |
| 6:15–6:40 | 一键升级 | 签名、授权、健康检查、恢复机制 |
| 6:40–7:00 | 总结页 | 原创贡献与应用价值 |

## 画面规范

- 全程显示银河麒麟 V11 桌面环境。
- 开头展示版本、架构和安装包摘要。
- 工具审批、记忆来源和同步状态使用近景。
- 指标页同时展示数据集、样本量、运行画像和阈值。
- 账号、密钥、用户目录、设备标识和网络地址全部脱敏。
- 视频采用 `.mp4`，分辨率不低于 1920×1080，时长不超过 7 分钟。

## 答辩一句话

PIXIU 让银河麒麟 OS Agent 的长期记忆从单机会话缓存，升级为可追溯、可遗忘、可在可信设备间安全收敛的分布式记忆网络。
