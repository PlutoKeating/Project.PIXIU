# PIXIU 项目报告与演示说明

## 项目报告

版本：0.1.12。内容按以下顺序组织：

1. 产品定位与用户场景。
2. 统一桌面、记忆引擎和系统 SDK。
3. 文档整理、偏好、跨会话记忆及来源。
4. 可信设备共享、断连恢复和并发更正。
5. 安装升级、测试结果与应用价值。

## 演示内容

演示顺序以 `submission/video-production/storyboard/shots.json` 为准。重点展示记录资料、换会话查询、查看来源、更正记忆、设备共享和遗忘操作。

账单示例的合计为 434.50 元，已与工具结果、公共 API 和原文核对。视频制作已取得真实跨端检索、同步检查点、偏好版本历史和原生桌面素材。

## 制作要求

| 项目 | 要求 |
|---|---|
| 格式 | 一份 ZIP，5—10 分钟，大小按交付规范控制在 200M 以内 |
| 画面 | 使用真实麒麟桌面，关键操作和来源采用近景 |
| 字幕 | 中文、清晰、与配音同步 |
| 数据 | 指标标注版本、环境和样本量 |
| 匿名 | 使用作品名称和公开合成资料 |

完整作品规则见 `docs/DELIVERY_PLAN.md` 第 0 节。制作过程与素材索引由视频工程维护。
