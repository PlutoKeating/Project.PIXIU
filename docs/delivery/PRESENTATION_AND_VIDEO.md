# PIXIU 项目报告与演示说明

## 项目报告

版本：0.1.12。当前正式报告为用户验收通过的34页科技风版本，保留用户新封面和尾页，全部备注已删除。六个章节为场景需求、方案架构、功能亮点、技术架构与实现方案、真实操作案例、商业探索。

两大亮点顺序为记忆共享，分布互连；自动记忆，持续整合。正文使用完整软件截图、原生标注与单句图注。场景和资料为公开合成内容，指标沿用实际测试环境与版本边界。

最终产物在 `submission/presentation-production/render/abc-trial/`，页序与输入摘要见该制作工程的 `review/abc-trial-manifest.json`。导出入口直接复制已验收PPT，不调用旧31页生成器。旧稿仅保留为历史制作资料。

## 演示内容

演示顺序以 `submission/video-production/storyboard/shots.json` 为准。目录监控与 Dreaming 展示“文件进入目录 → 后台整理 → 新会话使用 → 来源核对 → 更正审批”；多设备协作展示“配对授权 → 一端记录 → 另一端使用 → 重连补齐”。

账单示例的合计为 434.50 元，已与工具结果、公共 API 和原文核对。视频制作已取得真实跨端检索、同步检查点、偏好版本历史和原生桌面素材。

## 制作要求

| 项目 | 要求 |
|---|---|
| 格式 | 一份 ZIP，5—10 分钟，大小按交付规范控制在 200M 以内 |
| 画面 | 使用真实麒麟桌面，关键操作和来源采用近景 |
| 字幕 | 中文、清晰、与配音同步 |
| 数据 | 指标标注版本、环境和样本量 |
| 匿名 | 使用作品名称和公开合成资料 |

完整作品规则见 `docs/DELIVERY_PLAN.md` 第 0 节。制作过程与素材索引由视频工程维护。
