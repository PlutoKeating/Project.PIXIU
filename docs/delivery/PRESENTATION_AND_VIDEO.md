# PIXIU 项目报告与演示脚本

## 项目报告结构

1. 封面：作品名称与 0.1.9 版本。
2. 赛题问题：工具结果复用、知识更新与设备同步。
3. 作品定位：接入、检索、同步、遗忘与国产化适配。
4. 总体架构：桌面助手、MemoryProvider、引擎、基础服务和系统 SDK。
5. 核心创新：可信设备共享记忆、离线副本与重连对账。
6. 产品体验：跨会话找回账单、核对金额并查看来源。
7. 历史测试：原生验证、自动化回归及四项量化指标。
8. 作品价值：用户、OS Agent 与国产生态的实际用途。
9. 数据与算法：统一接入、结构化知识和三通道混合检索。
10. 偏好管理：提取偏好、保存历史与跨场景复用。
11. 流转与安全：分层保存、敏感过滤和精准遗忘。
12. 评测设计：固定数据集、指标计算与三组对比。

项目报告第 6 页使用本次跨会话账单召回实拍，对应金额和来源已核对。完整图片及未覆盖场景见[截图素材索引](assets/operations/截图素材索引.md)。

## 演示脚本（总时长须为 5-10 分钟）

视频要求为 5-10 分钟，以下安排为待录制脚本。录制时使用最终候选，实际演示助手任务和三设备操作，并核对画面与结果。

| 时间 | 画面 | 解说重点 |
|------|------|----------|
| 0:00–0:30 | V11 桌面、关于页 | 作品定位、版本、目标平台 |
| 0:30–1:10 | 安装与服务状态 | 单一 `.deb`、用户服务、两个系统 SDK 的运行状态 |
| 1:10–2:35 | Agent 多轮任务 | 规划、Shell/搜索、审批、工具结果写入 |
| 2:35–3:30 | 新会话召回 | 长期记忆复用、来源追溯、偏好适配 |
| 3:30–4:15 | 冲突与遗忘 | 版本审计、影响范围、二次确认 |
| 4:15–5:25 | 三设备同步 | 离线写入、并发更新、重连收敛、墓碑 |
| 5:25–6:15 | 测试报告 | 数据集、四项指标、V11 原生结果 |
| 6:15–6:40 | 一键升级 | 签名、授权、健康检查、恢复机制 |
| 6:40–7:00 | 应用价值 | 原创贡献与应用价值 |

## 画面规范

- 全程显示银河麒麟 V11 桌面环境。
- 开头展示版本、架构和安装包摘要。
- 工具审批、记忆来源和同步状态使用近景。
- 指标页同时展示数据集、样本量、运行配置和阈值。
- 账号、密钥、用户目录、设备标识和网络地址全部脱敏。
- 视频 1 份，5-10 分钟，压缩包为 zip，大小不超过 200M；建议配字幕。
- 作品内容一律不得出现学校、学院、校徽、指导教师及参赛学生姓名等可识别身份信息。

## 作品介绍用语

PIXIU 为银河麒麟上的智能助手保存长期记忆，让用户在新会话和可信设备上复用知识、核对来源并管理保留范围。
