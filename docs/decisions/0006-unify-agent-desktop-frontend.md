# ADR-0006：将 PIXIU 收敛为唯一 Agent 桌面应用

- **状态**：已批准（Accepted，待实施验证）
- **批准依据**：用户明确批准独立审查提出的全部建议，并要求列出完整计划、充分实施。
- **适用范围**：桌面宿主、自有管理界面、平台适配、构建打包及相关交付。

## 背景

代码同时交付 `kylin-agent` 与 `pixiu-frontend`。后者以聊天外壳承载记忆管理，且仍是通用构建回退。正式 Agent 界面尚未接入全部管理操作。仅隐藏或直接删除旧程序都会留下能力与兼容性缺口。

## 决策

1. 保留现有 openKylin Agent 为唯一桌面宿主，不重写 Agent 循环，不新建第三套前端。
2. 将记忆、证据、偏好、冲突、遗忘、设备同步、采集隐私和升级能力迁入同一应用。管理操作通过公共 HTTP/事件契约直接访问 PIXIU，不要求配置模型或让模型代替用户确认危险操作。
3. 自有 Qt 管理模块保存在 `frontend/` 可直接维护和测试的源码中；该目录不再代表独立产品。Module E 的 Provider 继续限于 `backend/agent/`，不导入后端私有实现。
4. `third_party/` submodule 保持只读。批准在导出副本上维护唯一宿主接入及必需的 SDK 可选适配补丁；完整管理实现不得藏入补丁，也不得据此扩展为无关上游重写。
5. 同一宿主支持麒麟 SDK 优先与 Debian 系无 SDK 路径。先完成替代能力和兼容验证，再删除独立小窗口、重复生命周期与启动回退。
6. 保留可靠控制器、通信逻辑、升级辅助程序和有效测试；重新整合界面，不照搬旧聊天、悬浮球、原始 JSON 阅读体验及未实现能力的开关。
7. 保留用户数据、设备身份、配置和会话历史。清理失效旧界面截图，不将其继续作为产品展示。

## 对既有决定的影响

- 替代 ADR-0001 决策第 4 项“保留独立演示控制台”；其唯一 Agent 基座、公共契约和原创范围约束继续有效。
- 延续 ADR-0003 的固定来源、许可证、离线供应链及证据要求。
- 在 ADR-0004 可审计宿主补丁机制上增加本决定限定的管理模块接入和 SDK 适配范围。
- 不改变 ADR-0002 用户会话服务模型与 ADR-0005 模型接入方向。
- 用户批准方案不等于任何平台或发布门已通过；推送与发布仍按当下有效授权执行。

## 完成条件

以 [完整任务计划](../UNIFIED_FRONTEND_PLAN.md) 的 U01—U16 为验收清单：唯一入口、能力无回退、数据保留、双平台证据、自动发布及真实截图缺一不可。批准此决定不表示迁移已完成。
