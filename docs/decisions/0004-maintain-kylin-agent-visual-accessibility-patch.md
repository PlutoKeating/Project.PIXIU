# ADR-0004：维护 KylinAgent 宿主视觉与可访问性下游补丁

- **状态**：已批准（Accepted）
- **提出日期**：2026-09-04
- **批准日期**：2026-09-04
- **决策人**：华南理工大学 PIXIU 团队负责人
- **适用范围**：openKylin Agent 桌面宿主的视觉、主题、文案与可访问性
- **前置决策**：[ADR-0001](0001-use-openkylin-agent-host.md)、[ADR-0003](0003-package-openkylin-agent-supply-chain.md)

## 背景

目标桌面实测暴露出宿主的严重主题冲突：应用级暗色调色板与页面内写死的浅色背景、
深色文字同时生效，导致侧栏、模型选择器、输入提示和按钮近乎不可读；空状态还显示
内部数据库路径。界面缺少清晰的信息层级和任务入口，不能作为最终作品的可用 Agent
交互面，也无法满足团队对基础可访问性的质量门。

`third_party/kylin-agent` 是固定的官方只读参考树。直接修改 submodule 会破坏来源追溯；
从零重写宿主又会越过 ADR-0001 确定的原创边界。因此需要一个独立、可重放、可审计的
下游视觉补丁。

## 决策

1. 保留上游会话、Runtime、SSE、工具调用和窗口生命周期，只重做桌面表现层；不以
   UI 补丁改变 Agent 业务语义。
2. 补丁保存在 `build/release/agent-host/patches/`，仅对从固定 commit 导出的隔离源码
   副本应用；上游 submodule 始终保持洁净。
3. 全局样式使用浅色/深色两组语义令牌，页面不得再写死与主题冲突的局部颜色。普通
   文本、次要文本、占位符、主按钮和消息气泡的目标对比度为 WCAG AA 4.5:1；焦点态、
   悬停态、禁用态和选中态必须可辨。
4. 宿主统一采用“PIXIU · KylinAgent / 分布式记忆工作台”产品层级，强化新建会话、
   云端模型选择、对话画布和输入区；空状态不得暴露数据库路径、用户目录或调试信息。
5. 自动化必须验证补丁可顺序应用、页面无局部 `setStyleSheet` 回归、关键语义选择器与
   云端模型文案存在，并从补丁令牌复算关键前景/背景颜色的对比度。
6. 发布前必须在银河麒麟 V11 分别检查浅色和深色主题、100%/125%/150% 缩放、键盘
   焦点、下拉列表、长会话滚动、流式输出、停止和错误态；截图只能作为视觉证据，不能
   替代功能测试。
7. 产品只允许直连云端推理：默认补入并优先选择 DeepSeek 官方 `deepseek-chat`，可选
   提供商限 DeepSeek、Anthropic、OpenAI；不展示 OpenRouter 中转或任何本地推理入口。
   密钥只进入 Runtime 的安全认证存储，不写入宿主配置模型清单或仓库。

## 结果与边界

- 允许维护比“最小编译修复”范围更大的表现层补丁，但任何新增业务能力仍须走
  Module E 与公共 API，不得进入该补丁。
- AGPL 对应源码交付继续包含固定上游、全部补丁和构建脚本；供应链记录必须绑定应用
  补丁后的真实宿主产物。
- 若上游提供同等质量且可重建的正式界面，优先回合上游实现；在替换前保留双主题和
  对比度回归门。

## 验收

- `test-agent-host-adaptation.sh`：补丁顺序、品牌层级、云端模型入口、隐私文案和局部
  样式禁令；
- `test-agent-host-ui-contrast.py`：关键文本与交互配色对比度不低于 4.5:1；
- 目标 V11 人工矩阵：双主题、缩放、键盘、空/加载/流式/错误/禁用状态；
- 完成同版重建、安装和截图复核后，才可把宿主 UI 标为最终候选通过。
