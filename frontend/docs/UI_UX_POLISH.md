## 1. 状态/语义颜色仍为内联硬编码

现行宿主由导出树 `ThemeManager` 管理明暗配色，管理页面复用同一应用样式。
服务诊断、查询、写入、更新、采集和同步分别有加载/错误/空态处理，但统一语义色、
危险操作辨识、禁用态与焦点对比仍须逐控件检查，不能宣称全部统一完成。

`0017` 为普通容器补齐主题背景，避免冲突背景与产品文字色混用；渲染回归检查
浅色→深色→浅色及输入框背景。V11 桌面启动曾出现黑底深色文字，新包实测仍须确认。

## 2. 字号/间距未完全统一

宿主全局正文样式为 14px，部分标题、辅助信息有单独规则；管理控件仍混用布局默认值。
需要在会话、记忆、设备、设置中统一标题层级、控件高度、段落留白和滚动区域。
长中文、英文、长 ID、金额及错误文案必须实际检查，不用已有测试条数代表布局完成。

## 3. 图标与悬浮球视觉

正式产品不保留独立悬浮球前端。应用菜单使用 PIXIU 图标，宿主窗口仍有上游机器人图标，
品牌图标及标题一致性尚未完成。宿主 desktop 标识已由 `0018` 对齐实际安装的
`com.kylin.pixiu.desktop`；任务栏关联须用对应新包验证。托盘、通知、快捷键必须归
唯一宿主所有，不能用另一种入口的截图冒充缺失入口已经实现。

## 4. 动效未完全落地

会话宿主已有流式消息和工具活动展示；管理操作通过在途状态、禁用控件和结果提示反馈。
仍须检查加载反馈、切页、长列表和退出确认是否稳定，避免动效遮挡状态或形成虚假成功。
不保留独立悬浮球角标动画作为当前产品展示。

## 5. 布局与窗口细节

正式入口是 `pixiu`，顶级导航为会话、记忆、设备、设置；管理能力嵌入同一宿主。
关闭最后一个可见窗口退出应用，`HostCloseGuard` 保护在途操作、未保存配置及 Agent
草稿/请求。录入、编辑、配对等对话框应保持所属窗口关系，不能重新变为第二个常驻前端。

需覆盖小屏幕、缩放、多屏位置恢复、长正文与窗口恢复，不把单一分辨率截图推广为全平台结论。

## 6. 主题/多端人工复测项（不属于自动修复）

- 从开始菜单启动已安装包，对照终端启动，核实进程对应的构建提交。
- 检查明暗切换后的容器、输入框、列表、菜单、标签、危险按钮和焦点可读性。
- 检查鼠标首击、键盘导航、对话框关闭、草稿保护和在途操作保护。
- 检查 HiDPI、多屏及各目标架构；通用 OFF 与 V11 ON 结果分别记录。
- 配对二维码需要实际识别和双设备操作，不以画出二维码作为配对完成。
- 新截图必须来自真实安装包和实际接口，记录来源、状态和限制；图库仍待重拍。

## 2026-08-10 Round 3（长文案布局鲁棒性 + 指针/焦点细节收尾）

长设备名及不同语言下的裁剪、滚动、焦点可见性，不宣称现行界面已全部通过。

## 2026-08-10 真实 UKUI 桌面 UI 演示（Round 4/展示轮）

## 2026-08-10 Round 5（侧边浮窗主视觉统一）

侧边独立浮窗不是当前产品方向。现行工作围绕唯一宿主统一视觉，不继续维护第二套聊天窗口。
有价值的欢迎引导、快捷操作、信息层级和窄屏适配可迁入正式界面，但迁移完成与否必须
依据实际接线和测试，不能只复制外观。

## 2026-08-10 Round 6（第一批需求补齐：置顶/菜单/建议卡片/chip/多行输入/badge）

现行宿主的会话输入与管理导航独立分工。建议内容不得自动发送；全局状态不能只由一次
HTTP 可达检查推断。服务诊断页提供只读健康/版本/能力快照，并非持续状态中心。
置顶、快捷操作、通知和状态汇总需按唯一宿主方案验收，不展示旧控件作为现成功能。

## 2026-08-10 Round 7（去重复入口 + 功能弹窗与对话严格独立）

主导航已经收拢到唯一宿主，设置入口负责模型配置、采集隐私、升级和服务诊断。
仍须检查入口重复、对话框归属及关闭行为。最后窗口关闭应退出，不保留无托盘的隐形常驻；
有未完成操作时须由关闭保护阻止退出或要求明确处理，不能以结束进程代替正常操作。
