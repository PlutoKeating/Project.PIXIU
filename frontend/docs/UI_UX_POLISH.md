## 2. 字号/间距未完全统一

- 顶栏/标题多处直接 `setStyleSheet("font-size: …px")`（11/12/14px）或
  `setPixelSize`，与 `frontend/docs/ARCHITECTURE.md` §7.2 字号分级
  （14/11/9pt）不完全一致；Polish 阶段统一为设计令牌。
- 气泡内边距（4px/10px）与设计稿（12px/10px）存在差异；同步 Tab 节点行、
  证据卡、输入栏间距以设计栅格（4/8/12/16）复核。
- `styles.qss` 中的 `QListWidget#messageList` 背景透明、列表滚动条样式未定制。

## 3. 图标与悬浮球视觉

- 悬浮球中央字符为硬编码“貔”（`FloatingBall::paintEvent`），Polish 阶段替换为
  资源图标（明/暗两套，随 UKUI 系统图标主题），并评估多倍图资源。
- 托盘/desktop 已用内嵌 `pixiu.svg`；悬浮球角标样式（红点、99+）需与设计稿
  复核。
