# 一段记忆的旅程

不安装软件，也能先理解 PIXIU 的基本操作顺序。这是本网站的可操作教学演示，计算发生在浏览器内。

<MemoryDemo />

## 试着完成这四件事

1. **记住**：查看合成支出清单，理解结构化内容与原始来源的关系。
2. **找回**：展开来源，核对三项金额与合计。
3. **更正**：修改燃气费，再回到「找回」。合计根据你的输入重新计算。
4. **遗忘**：先预览范围，尝试取消；再次预览并确认后，「找回」会显示已隐藏。

## 演示与产品的区别

| 维度 | 当前网页演示           | 桌面产品                               |
| ---- | ---------------------- | -------------------------------------- |
| 数据 | 预置合成数据，刷新重置 | 当前用户持久化记忆                     |
| 查询 | 预设问句与浏览器求和   | 关键词、向量与关系检索                 |
| 共享 | 只显示范围示意         | 配对与可信传输后同步                   |
| 更正 | 当前页面变量变化       | 乐观锁、证据与索引更新                 |
| 遗忘 | 隐藏当前示例           | 两段确认、知识隐藏、向量移除、共享墓碑 |

该练习没有连接模型、SDK、后端或其他设备，不衡量真实召回率、时延或同步能力。桌面实拍需在对应安装包完成真实操作验证后单独补充。
