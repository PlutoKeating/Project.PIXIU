## 数学公式

行内表达：$S=\sum_{i=1}^{n}a_i$。独立公式：

$$
S = 210 + 68.50 + 156 = 434.50
$$

公式在构建时通过 MathJax 渲染，不需要从远程 CDN 加载数学字体脚本。

## 时序图

```mermaid
sequenceDiagram
    actor 用户
    participant 页面
    participant GitHub
    用户->>页面: 打开下载页
    页面->>GitHub: 请求最新正式发布
    alt 获取成功
        GitHub-->>页面: 版本、说明、附件
        页面-->>用户: 展示实时数据
    else 网络失败或限流
        页面-->>用户: 原因与重试入口
    end
```
