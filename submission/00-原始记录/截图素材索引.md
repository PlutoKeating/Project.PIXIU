## 演示数据与复现操作

所有新录入的支出均为公开合成演示数据：2026 年 9 月电费 210 元、水费 68.50 元、
燃气费 156 元，合计 434.50 元。它们不是用户真实财务信息。

1. 下载并核验上述 Release 的安装包。在终端实际执行
   `sudo dpkg -i pixiu_0.1.8-1_amd64.deb`，等待安装成功后运行 `pixiu`。
   如使用图形界面，选择“打开方式 → 安装器”，或执行
   `kylin-installer pixiu_0.1.8-1_amd64.deb`；本次桌面默认 deb 关联为归档工具，
   不能将普通双击描述为必然启动安装器。
2. 新建 Agent 会话，保持系统云模型，请求记住合成清单并用表格回答。
   展开工作过程，随后新建另一个会话，要求从长期记忆查询清单，不能重新提供金额。
3. 打开设置切换浅色/深色主题；打开云模型设置查看官方直连入口。
   本次不修改模型授权，不保存任何 API Key。
4. 请求模型生成四步 Mermaid 流程、求和 LaTeX 公式与三行 Python 示例。
   另执行只读任务查询系统名称、包版本和 openKylin 官方网页，展开真实工具过程。
5. 在记忆控制台点“录入”，填写图 18 的标题和正文，确认本机作用域后提交；
   检索这个独有标题，点击“查看原文”得到图 20。设置中打开关于、检查更新。

## 采集工具与文件校验

仓库工具 `backend/scripts/capture_desktop.py` 向运行中的 libvirt 桌面发送真实输入。
全屏通过 `virsh screenshot` 采集；本批也使用来宾 `import -window root` 取得同一实际
桌面帧，终端区域用实时区域采集。工具不生成或修改软件界面。
宿主需 Python 3 与 virsh；来宾区域采集需 SSH、ImageMagick，X11 文本粘贴需 GTK 3
Python 绑定。这些仅为采集工具依赖，不增加安装包依赖。

```bash
python3 backend/scripts/capture_desktop.py --guest USER@HOST --domain DOMAIN \
  --width 1920 --height 1080 capture /var/tmp/new-pixiu-screen.png
python3 -m unittest discover -s backend/scripts/tests -v
```

输出目录须预先存在，已有图片拒绝覆盖。坐标必须匹配实际分辨率。
X11 剪贴板在原生 Wayland 窗口中可能不同步；本次控制台改用 AT-SPI 的实际可编辑
文本控件输入，并逐次检查画面后才提交。没有使用后台数据库注入来伪造 UI 操作。
PNG 通过 Git LFS 管理；克隆后先执行 `git lfs pull`，再按截图清单核对摘要。
