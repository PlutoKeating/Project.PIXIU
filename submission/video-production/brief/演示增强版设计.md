# 演示增强版制作基准

2026-09-11。创作模式：自主创作，依据用户认可的功能范围重剪画面与口白。

## 观看目标

面向第一次了解 PIXIU 的评委、专家和领导。观众能够说清软件的用途，跟随实际操作理解资料如何保存、查找、更正和跨设备复用。

每段按“用途与日常需求 → 假设一个具体场景 → 实际操作 → 结果与价值”展开。承接同一示例时使用“接着”“这份资料”等明确指代。新示例显式说出“假设”。系统机制用日常语言解释，必要技术名词随功能解释出现。

## 画面方向

软件自身的蓝白配色、原生控件和内容排版构成主体。选用连续桌面演示：鼠标先指向入口，相机平稳推近，实际点击引起页面变化，最后跟随鼠标核对结果。章节标题、简短注释与字幕帮助定位当前动作。

色板：背景 #f6f7f9，表面 #ffffff，正文 #172033，强调 #1456b8，次要文字 #526477，分隔 #dce2ea。字体 Noto Sans CJK SC。1920×1080、30fps。标题 54px、说明 32px、字幕 60px；软件内容在关键阅读时段推近展示。

主体区域横向占据画面约九成。全局视图交代入口与位置；操作特写跟随控件、正文和来源；结果停留约 1.5–2.5 秒。图解采用模块连线、逐步展开和当前节点强调。鼠标移动采用有起落速度的弧线，操作落点与真实控件坐标一致。

动效参数：专业、清晰、从容；普通移镜 24–42 帧，阅读特写 45–75 帧，近景倍率按原图清晰度校准。鼠标与相机共用页面坐标。实际点击保留可核对的发生时刻。

## 镜头语法依据

读取 video-shotcraft 的 pipeline、aesthetic-rules 与 final-review。参考 Gallery `cursor-flyover · cursor-flyover`，准确实现为 `demos/camera/cursor-flyover/CursorFlyover.tsx`：继承连续视点、同坐标光标与相机、平滑加减速和落位阅读。导航巡览使用这张卡的运动结构；其余真实操作依据录像时刻设计专用相机路径。

真实操作画面由当前 0.1.12 软件生成，录入与查询使用公开合成资料。现有原录用于完整过程的补充，记录各段源时刻。针对截图的鼠标指引用于说明可见内容，实际点击与状态变化由操作录像呈现。

品牌首尾、架构图、同步观测和量化结果沿用既有事实。历史指标保留实际环境与样本量。图解和实拍在叙事中说明各自展示的内容。

## 声音与交付

沿用 Azure zh-CN-YunfengNeural、语速 0%，按修订文本生成词级时间并安排阅读停顿。沿用用户选定配乐及混音比例。保留带配乐与无配乐两版，正式视频按冻结要求装入 ZIP。

制作顺序：关键画面预览 → 逐镜用途、场景与动作计划 → 原录与坐标 → 旁白、字幕与画面配合 → 成片 → 独立审查 → 修订与完整检查 → 本地提交。

独立审查提供本基准、分镜、源素材、准确参考实现、成片及关键帧，重点检查鼠标落点、口白动作配合、画面可读性、场景交代、首尾一致和功能覆盖。

本轮新增口白统一采用原始语速（0%）；片头与片尾复用已指定的原音。操作节奏通过镜头编排和停顿配合口白。

字幕沿用 49e463c 的现有版本：Noto Sans CJK SC、60px、700 字重、白字、7px 黑色描边、原阴影、底部 57px、行高 1.15，排版与渲染组件按原文件保留。

镜头库筛选记录：扫描全部镜头卡的前置信息，选择 cursor-flyover 的连续视点与光标引导结构；真实输入时刻驱动点击反馈，截图指引按正文阅读顺序移动。相机以原速口白和实际操作为节奏依据，配乐采用既定的 15% 音量。
