# 制作依据与镜头约束

模式：用户明确选择 Ink Press 模板。保持品牌压印→聚焦主角→字卡呼吸→发牌检索→详情→列表压入→文档呈现→收尾组装的运动语法，扩展真实操作段以满足 5–10 分钟及功能完整要求。不是把 36 秒模板慢放成九分钟。

中心主旨：麒麟 OS Agent 的记忆优化；最关键原创亮点是可信多设备的 Agent 集体记忆共享，以及跨设备复用、离线恢复、并发收敛、范围隔离和分布式遗忘。

## 视觉依据

源码取自 `build/release/agent-host/patches/0004-working-agent-experience.patch` 的宿主主题定义及 `frontend/docs/ARCHITECTURE.md`。现有 V11 实拍已核对为白色控件、浅灰背景、科技蓝强调。

| 令牌 | 颜色或规则 |
|---|---|
| 背景 | `#f6f7f9` |
| 表面 | `#ffffff` |
| 正文 | `#172033` |
| 强调 | `#1456b8` |
| 边框 | `#dce2ea` |
| 次表面 | `#edf1f5` |
| 字体 | Noto Sans CJK SC／产品实际中文无衬线字体；渲染前固定字体文件 |
| 排版 | 1920×1080，30 帧；字幕至少 36 像素，留独立底部安全区；画面结果留阅读时间 |
| 材质 | 克制的浅色表面与柔和阴影，去除模板琥珀色与暖纸底；不使用大面积深色或霓虹 |

原版开场的 82–220 帧参数与新版聚焦卡文档存在差异：文档要求落地后相机完全静止至少 15 帧，而原版末段仍有微缩放。适配时采用更严格的静止要求并延长落定段，记录具体帧号。开头和结尾字标落定至少 30 帧。

## 内容与证据

现有资料存在历史设计承诺与当前实现不一致之处。以当前正式宿主、公共 API、真实操作和新文档为准：取消的悬浮球不出镜；无完整 OCR 的包不宣称图片识别已成功；遗忘不宣称原始证据全部物理擦除；历史 portable 指标不冒充 V11 指标；共享配对成功不冒充送达。

初始只有一台 V11 虚拟机，原设备截图为同步关闭状态。现已在同一物理宿主建立三台独立 V11 虚拟机，取得双向信任、共享、断连补齐、并发收敛、遗忘传播及显式 Agent 工具复用证据，双 SDK 使用实际 kylin runtime。此环境不冒充三台物理设备验收；当前安装包上加载开发修复，最终须重建同版候选。抽象示意图不得标为实测。

已有 38 张原始截图完整复制至 `raw/screenshots`，摘要与原仓库文件一致。部分图含英文工具名、诊断枚举、机器标识和桌面区域；需逐镜选择裁切或重新采集中文任务，不能直接批量入片。画面、口白与字幕以中文为主，少量必要专业词汇保留。

口白按镜头逐句生成，字幕时间由实际音频测量驱动，不按字符均摊估计。操作段等待时间可剪辑，但必须保留输入、执行与结果的因果关系；加速明确标注。声轨采用中文解说与克制音效，暂不加背景音乐。若后续加音乐，同时间线另导出无背景音乐版。

完成检查：成片逐镜关键帧、整片回看、音轨峰值与解说清晰度、逐句字幕同步、ZIP 内视频可解码、实际时长与大小、匿名内容、功能覆盖，以及 video-shotcraft 要求的干净上下文独立终检。检查通过后打开动效工作台。
