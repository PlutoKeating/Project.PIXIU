# PIXIU 交付材料导览

PIXIU 为银河麒麟 V11 上的智能助手保存长期记忆，支持跨会话复用、来源查看和可信设备同步。本目录保存交付工作稿，完整操作截图、最终评测、源码重建和目录整理仍待完成。

## 阅读材料

先阅读项目报告了解产品，再查看技术方案中的架构、安装、使用方法和测试记录。各分篇 Markdown 用于维护内容，已汇入主技术方案。

| 内容 | 工作稿位置 |
|---|---|
| 项目报告 | `01-项目报告/PIXIU项目报告.pptx` |
| 技术方案 | `02-技术方案及测试结果/PIXIU技术方案及测试结果.pdf`，另有 Word 稿 |
| 源码与技术规范 | `03-源代码及规范/` |
| 安装操作说明 | 主技术方案的部署章节；分篇位于 `04-部署文档/` |

## 正式提交要求

最终提交项目报告、技术方案、功能演示视频和完整源代码各一份。技术方案汇入用户手册、安装说明、测试结果和效果验证报告。视频时长为 5-10 分钟，以 zip 提交，大小不超过 200M。

份数、格式、两层目录名称和匿名要求按仓库 `docs/DELIVERY_PLAN.md` 第 0 节执行。作品内容中的封面、页脚、图片及署名均需检查身份信息。

## 当前版本与历史材料

文字稿按产品 0.1.9 更新。2026-09-08 实拍的“服务与能力”页面已用于项目报告，显示桌面与后端版本一致、两个系统 SDK 使用麒麟实现。其他核心操作截图仍待采集。

`04-部署文档/01-可安装软件/` 中的软件包和源码归档均为 0.1.7 历史材料。原生 JSON 记录也来自旧候选。准备正式提交时，需要重建同版源码并补齐对应测试结果。
