# PIXIU 交付材料导览

## 一句话介绍

PIXIU 是面向银河麒麟桌面操作系统 V11 的 OS Agent 分布式记忆系统，让偏好、知识和工具经验能够跨会话复用、跨设备同步、按来源追溯，并通过自然语言安全遗忘。

## 建议阅读顺序

1. `01-项目报告/PIXIU项目报告.pptx`：用最短时间了解问题、方案、创新与结果。
2. `02-技术方案及测试结果/PIXIU技术方案及测试结果.pdf`：查看完整架构、核心机制和测试结论。
3. `02-技术方案及测试结果/01-用户手册/`：按用户视角体验 Agent、记忆、同步和遗忘。
4. `02-技术方案及测试结果/02-效果与测试证据/`：核对量化结果与机器可读证据。
5. `04-部署文档/`：在银河麒麟 V11 校验并安装单一 `.deb`。
6. `05-功能演示视频/PIXIU功能演示.mp4`：观看 7 分钟端到端演示。

## 核心创新

- 多源记忆：统一接入对话、工具结果、用户行为、手动配置与 OCR。
- 神经—符号检索：BM25、向量与实体关系图融合，结果可追溯。
- 分布式记忆：CRDT、Gossip 与反熵支持离线写入和最终一致。
- 安全遗忘：自然语言定位、二次确认、级联清理与墓碑防复活。
- 国产化适配：V11 生产链路使用系统 Embedding 与 Vector Engine SDK。

## 原创与上游边界

团队原创部分是 PIXIU 记忆引擎、检索与流转、分布式同步、MemoryProvider、双 SDK 产品接线、管理控制台、评测与发布体系。

openKylin `kylin-agent` 和 `agent-runtime` 提供通用会话、规划、工具和审批能力。交付包披露固定版本、许可证、对应源码、补丁、SBOM 和 NOTICE，不将上游能力宣称为团队原创。
