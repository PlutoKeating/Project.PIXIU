# PIXIU 用户手册

## 认识 PIXIU

PIXIU 在同一个窗口中提供“会话、记忆、设备、设置”四个入口。您可以让助手执行任务，保存和查找记忆，查看来源，并管理采集权限、可信设备和软件更新。

本手册按 0.1.9 编写，插图来自银河麒麟 V11 的实际操作。全部 38 张原图及未完成场景见[截图素材索引](../../00-原始记录/截图素材索引.md)。示例均为公开合成数据。

## 启动并检查版本

安装后，从应用菜单打开“PIXIU”，或在终端运行 `pixiu`。安装步骤和对应画面见部署指南。进入“设置 → 服务与能力”，点击“读取服务与能力”，检查桌面与后端版本、数据库状态和系统 SDK。

## 录入、检索和修改记忆

进入“记忆 → 检索与录入”，点击“录入记忆”，填写标题和正文，选择使用范围。本例选择“Agent 记忆（user:default）”，让管理页与助手使用同一范围。点击“保存记忆”后检查回执，再返回检索。


![图 5：填写演示账单并选择 Agent 记忆范围。](../../00-原始记录/01-图片记录/10-memory-input.png)

图 5：填写演示账单并选择 Agent 记忆范围。



![图 6：检索账单，点击“查看来源”阅读正文。](../../00-原始记录/01-图片记录/12-memory-evidence.png)

图 6：检索账单，点击“查看来源”阅读正文。

查询范围要与保存范围一致。点击“其他范围…”可以输入独立范围名，例如 `user:work`。打开来源后可阅读正文；需要检查结构时，勾选“查看原始数据（高级）”。长正文可在阅读区向下滚动。

检索到需要修改的记忆后，点击“编辑命中记忆”。本例将手动录入账单的燃气费改为 186 元，合计改为 464.50 元。保存后点击“重新读取”，检查金额和版本。助手先前保存的账单是另一条记录。


![图 7：修改正文中的燃气费和合计。](../../00-原始记录/01-图片记录/14-memory-edit.png)

图 7：修改正文中的燃气费和合计。



![图 8：重新读取后确认版本 2 和新金额。](../../00-原始记录/01-图片记录/15-memory-version.png)

图 8：重新读取后确认版本 2 和新金额。

如果其他操作先更新了同一条记忆，旧版本保存会被拒绝，输入仍保留。先复制需要保留的修改，再点击“重新读取”，确认后按最新内容重新编辑。高级 JSON 格式不完整时，保存按钮会禁用，补齐格式后再保存。

## 查看偏好和历史

在来源页选中一条表达偏好的证据，再进入“偏好与审计”，点击“从当前证据提取偏好”。选择对应范围并刷新，点击偏好条目查看历史。

本例先录入“回答简洁”，再录入“回答详细”。当前要求变为详细回答，历史保留之前的简洁要求。界面中的 `compact` 表示简洁，`verbose` 表示详细。提取依据当前规则与证据，仍需核对是否符合原意。


![图 10：当前偏好为详细回答，历史仍保留简洁回答的版本。](../../00-原始记录/01-图片记录/62-preference-changed.png)

## 遗忘记忆

进入“安全遗忘”，选择保存时的范围并描述目标，点击“预览匹配目标”。逐条核对标题、范围和数量。本例使用独立演示范围，只预览本次创建的一条临时便笺。


![图 11：预览只命中一条演示便笺，尚未执行遗忘。](../../00-原始记录/01-图片记录/25-forget-target.png)

点击“取消并清除本页预览”可以退出本次操作。要继续遗忘，重新预览并核对后，点击“已核对以上目标，确认遗忘”，查看后端结果。

遗忘会隐藏知识并移除检索向量，原始证据和部分关联数据仍保留。共享记录还需等待其他设备同步。预览过期或知识版本变化时，请重新预览；本界面不提供撤销。

## 连接可信设备

两台设备需要使用相同共享域，并分别完成令牌交换。先读取设备状态，检查同步开关。本次只有一个本机节点，多设备配对与送达尚未实测。

1. 两端打开“交换配对令牌”，选择相同方式。
2. 使用 PIN 方式时，设置六位数字 PIN 并生成本机令牌。令牌有效期为五分钟。
3. 通过可信渠道交换令牌，通过另一可信渠道告知 PIN。
4. 两端分别填写对方令牌和 PIN，点击“验证对端令牌并建立本地信任”。
5. 刷新节点，完成共享写入和对端检索，确认数据实际送达。


![图 17：配对入口与双端操作说明。画面尚未生成令牌。](../../00-原始记录/01-图片记录/41-pair-dialog.png)

图 17：配对入口与双端操作说明。画面尚未生成令牌。

设备发现、节点在线记录和队列为空都不足以证明数据送达。暂停传输、离线恢复和解除信任后，也应在双方核对实际状态。私人记忆保留在本机。

## 模型与主题设置

进入“设置 → 应用与升级”，点击“模型与 Agent 配置…”。主题切换立即生效；“管理云端模型”可以选择模型并检测连接。麒灵系统云模型跟随系统“AI 模块管理”中的首选模型和授权。


![图 18：系统模型连接检测通过，PIXIU 跟随系统首选模型。](../../00-原始记录/01-图片记录/54-model-check.png)

图 18：系统模型连接检测通过，PIXIU 跟随系统首选模型。

配置其他服务时填写模型 ID、API 地址和密钥，点击“检测并保存”。密钥应保留在配置界面和 Runtime 中，截图或报告不得公开。

## 检查软件更新

进入“设置 → 应用与升级”，点击“检查更新”。本次返回 0.1.9 已是最新版本。


![图 19：实际更新检查返回已是最新版本。](../../00-原始记录/01-图片记录/51-update-check.png)

图 19：实际更新检查返回已是最新版本。

有新版本时，软件依次下载文件、核对签名、请求系统授权、安装并检查服务。升级前保存工作，成功后按提示重启整个应用。升级失败时查看恢复结果，确认服务恢复后再继续使用。本次尚未验证完整图形升级和回滚事务。

## 常见问题

| 现象 | 处理方式 |
|---|---|
| 助手无法连接记忆服务 | 在“服务与能力”重新读取状态，再按部署指南查看服务日志 |
| 搜索结果为空 | 核对保存范围和关键词，确认写入已成功 |
| 保存提示版本冲突 | 复制修改，重新读取最新版本后再编辑 |
| 设备无法发现 | 检查网络、同步开关和防火墙；继续核对双方信任 |
| 遗忘后对端仍显示旧内容 | 等待对端上线并对账，再刷新查询 |
| 更新失败 | 阅读签名、架构或网络错误，核对恢复后的服务状态 |
