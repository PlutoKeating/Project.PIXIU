# PIXIU 用户手册

## 认识 PIXIU

PIXIU 由 KylinAgent 和记忆控制台组成。KylinAgent 用于多轮对话、任务规划和工具执行；记忆控制台用于查看、录入、同步和删除记忆。

## 启动

安装后从应用菜单打开“PIXIU”，或在终端运行：

```bash
pixiu
```

首次启动会初始化当前用户的配置、数据库、后台服务和 PIXIU MemoryProvider。主界面可查看后端连接、版本和同步状态。

## 使用 Agent

1. 打开 KylinAgent，点击“新建会话”。
2. 保持默认的“麒灵系统云模型”，或选择自己配置的官方直连模型。
3. 输入任务并发送；运行中可随时停止。
4. 风险工具出现授权提示时，核对动作后再决定是否允许。
5. 点击记忆来源可查看相关 evidence。

“麒灵系统云模型”直接使用系统“AI 模块管理”中的首选模型和授权，无需向 PIXIU
提供 API Key。需要使用自己的服务时，打开“云端模型设置”，选择 DeepSeek、
Anthropic 或 OpenAI，填写模型 ID、API 地址和 API Key，然后点击“检测并保存”。
输入内容以密码形式显示，连接检测通过后立即生效。

## 管理记忆

在记忆面板中输入自然语言即可检索长期记忆。结果会显示内容、置信度、作用域、状态和来源。手动录入适合保存经过确认的事实、规则、工作流和配置。

偏好页展示操作习惯、输出风格和安全策略。每次变更保留版本历史，可查看系统何时、依据什么信息形成偏好。

冲突页展示新旧知识、裁决方式和时间。自动裁决不会删除旧证据，便于回溯；需要人工处理的冲突会保持显式状态。

## 连接多台设备

1. 在设备 A 打开“同步与设备”，生成配对请求。
2. 在设备 B 核对设备名称和六位 PIN。
3. 双方确认后完成可信配对。
4. 在节点列表中查看在线状态、积压操作和最近同步时间。

只有共享作用域的记忆会同步。私人作用域始终保留在本机。暂停同步不会影响本地写入；恢复后系统会自动反熵对账。

## 精准遗忘

1. 用自然语言描述要忘记的内容。
2. 查看系统列出的知识、证据和关联项。
3. 确认范围后执行遗忘。
4. 再次检索，确认内容不再出现。

当前遗忘并非全部数据擦除：原始证据、关系及 FTS 载荷仍可能保留；操作主要使知识
不可检索并移除向量。界面的关联数量为预览，不代表已物理删除的记录数。

共享记忆会生成删除墓碑并传播到可信设备。用户确认影响范围之前，系统不会执行删除。

## 更新软件

在“设置 → 关于与更新”查看当前版本、可用版本和组件兼容状态。选择更新后，系统依次完成下载、摘要与签名校验、系统授权、安装和健康检查。

更新成功后可立即重启客户端。若安装或健康检查失败，界面会明确显示恢复结果；在恢复状态确认前不要继续写入重要数据。

## 隐私控制

行为采集可在设置中关闭。敏感信息默认限制在本机，不进入共享域和 Agent 上下文。设备配对、风险工具、遗忘和升级都有独立确认步骤。

## 常见问题

| 现象 | 处理方式 |
|------|----------|
| Agent 无法连接记忆服务 | 检查设置页服务状态，再运行 `systemctl --user status pixiu-backend.service` |
| 设备无法发现 | 确认同一局域网、同步已开启、防火墙允许服务通信 |
| 搜索结果为空 | 核对作用域、时间范围和关键词，确认记忆已完成写入 |
| 更新被拒绝 | 核对网络、软件架构、版本与签名文件是否匹配 |
| 遗忘后其他设备仍显示旧值 | 等待设备上线并完成反熵对账，再刷新状态 |
