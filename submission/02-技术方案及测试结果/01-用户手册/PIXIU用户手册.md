# PIXIU 用户手册

## 认识 PIXIU

PIXIU 在同一个窗口中提供“会话、记忆、设备、设置”四个入口。您可以让助手执行任务，保存和查找记忆，连接可信设备，并管理采集权限和软件更新。

本手册按 0.1.9 的界面入口编写。完整操作截图仍待采集，取图任务见交付材料中的截图素材索引。

## 启动

安装后，从应用菜单打开“PIXIU”，或在终端运行：

```bash
pixiu
```

首次启动会创建当前用户的配置和数据库，并启动后台服务。进入“设置 → 服务与能力”，点击“读取服务与能力”，可查看桌面版本、后端版本和服务状态。

## 使用助手

1. 在“会话”中新建会话。
2. 选择“麒灵系统云模型”，或选择已配置的模型服务。
3. 输入任务并发送。执行期间可点击停止。
4. 工具请求授权时，阅读将执行的操作，再决定是否允许。
5. 点击“本会话记忆来源”，查看助手使用的原始记录。

“麒灵系统云模型”使用系统“AI 模块管理”中的首选模型和授权。如需配置其他服务，进入“设置 → 应用与升级”，点击“模型与 Agent 配置…”，打开云端模型设置。选择服务商，填写模型 ID、API 地址和密钥，然后点击“检测并保存”。

## 查找和保存记忆

进入“记忆”，选择使用范围并输入查询。结果包含内容、置信度、状态和来源。打开来源可查看支持这条知识的原始记录。

手动录入适合保存已确认的事实、规则和工作步骤。保存失败时，界面会保留输入；按错误提示处理后可重试。编辑已有知识时，如果其他操作已更新同一条记录，请重新读取最新内容再修改。

偏好页面显示操作习惯、输出风格和安全策略。选择一项偏好可查看历史版本。冲突页面提供新旧知识、处理方式和时间，供您核对系统的处理结果。

## 连接多台设备

两台设备需要使用相同的共享域，并分别完成令牌交换。配对令牌用于验证设备身份，请通过可信渠道交给对方。

1. 在两台设备的“设备”页分别打开“交换配对令牌”，选择相同的配对方式。
2. 使用 PIN 方式时，为本机令牌设置六位数字 PIN，再点击“生成本机令牌”。令牌有效期为五分钟。
3. 交换令牌，通过另一可信渠道告知 PIN。在各自窗口粘贴对方令牌并填写对方 PIN。
4. 两端分别点击“验证对端令牌并建立本地信任”。
5. 返回设备列表，刷新并检查双方的信任、在线状态和待同步操作。

二维码方式也支持复制令牌文本。双向信任建立后，还需通过实际共享写入和对端检索确认同步结果。设备重连时会自动比较记录并补齐遗漏；私人记忆保留在本机。

## 遗忘记忆

1. 在记忆工作区的遗忘页面描述目标，例如“忘记四月份账单”。
2. 预览目标，核对知识内容、使用范围和相关记录数量。
3. 确认目标无误后执行遗忘。
4. 再次检索，检查该内容已隐藏。共享记录还需等待其他设备同步。

遗忘会隐藏知识并移除检索向量，原始证据和部分关联数据仍会保留。预览过期或知识版本变化时，请重新预览后确认。

## 更新软件

进入“设置 → 应用与升级”，点击“检查更新”。选择版本后，软件会下载文件、核对签名，请求系统授权，再安装并检查服务。

升级前保存正在进行的工作。安装和健康检查成功后，按界面提示重启整个应用，使新版本生效。升级失败时，先查看恢复结果；确认服务恢复后再继续使用。

## 管理采集权限

进入“设置 → 采集与隐私”，读取当前配置后，选择需要的采集来源和目录，再保存。新用户的采集开关默认关闭。保存后查看采集日志，确认文件是否成功读取。

当前界面提供目录和行为采集设置，剪贴板与自动截图功能尚未实现。敏感内容限于本机使用。关闭采集会停止后续采集，已有记忆继续保留。

## 常见问题

| 现象 | 处理方式 |
|---|---|
| 助手无法连接记忆服务 | 在“设置 → 服务与能力”重新读取状态，再按部署章节查看后台服务日志 |
| 设备无法发现 | 检查局域网连接、同步开关和防火墙设置 |
| 搜索结果为空 | 检查使用范围、时间和关键词，并确认内容已保存 |
| 更新被拒绝 | 阅读错误提示，检查网络、软件架构和签名校验结果 |
| 遗忘后其他设备仍显示旧内容 | 等待设备上线并完成对账，再刷新查询结果 |
