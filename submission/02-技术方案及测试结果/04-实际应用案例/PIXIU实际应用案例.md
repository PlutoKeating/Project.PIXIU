# PIXIU 应用案例

下列案例说明两组任务的操作过程。最终候选版本的实操结果和截图仍待补齐。

## 案例一：家庭支出检索

### 场景

家庭成员通过对话、手动录入或已识别的图片文本保存多个月份的水、电、燃气账单。用户只记得模糊描述，希望立即得到准确金额，并能追溯原始清单。

### 操作过程

1. 将已识别的账单文本交给系统，检查格式、质量和敏感信息。
2. 系统提取月份、类别、商户和金额，建立实体关系。
3. 内容写入关键词、向量和关系图三类索引。
4. 用户询问“上个月水电燃气花了多少”。
5. 系统按时间范围召回账单，并对结构化金额聚合。
6. Agent 返回分类明细，并附原始记录来源。

### 价值

用户可以用自然语言查询不同月份的账单。系统查找相关记录并按字段汇总金额，用户可打开来源检查每笔费用。

### 遗忘

用户要求“忘记四月份账单”时，系统先列出目标和相关记录数量。用户确认后，知识从检索结果中隐藏，向量被移除，共享设备收到删除记录。原始证据和关系数据仍会保留。

## 案例二：跨设备工作流复用

### 场景

用户在办公设备 A 上通过 Agent 完成资料检索、Shell 处理和报告整理，希望在设备 B 上继续使用已保存的工作步骤。私人数据保存在各自设备中。

### 操作过程

1. Agent 在设备 A 调用工具，风险操作经过用户审批。
2. PIXIU 保存有价值的工具结果与操作顺序，形成工作流知识。
3. 共享工作流通过可信设备网络传播，私人记忆保留在设备 A。
4. 设备 B 离线期间仍可使用本地记忆并记录新偏好。
5. 设备恢复联网后，Gossip 与反熵完成增量对账。
6. 新会话中的 Agent 召回最终工作流，并依据设备 B 的本地偏好调整输出。

### 并发与删除

两台设备并发修改同一共享知识时，CRDT 使用版本向量和确定性规则收敛。语义上互相矛盾的不同知识由冲突服务仲裁并保留审计记录。

任一设备删除共享条目后，墓碑会传播到其他可信节点。曾离线的旧副本重新加入时，系统根据删除记录继续隐藏相应内容。

## 案例与赛题要求映射

| 赛题要求 | 家庭支出 | 跨设备工作流 |
|----------|----------|----------------|
| 多源接入 | OCR、对话、手动配置 | 对话、工具结果、用户行为 |
| 偏好记忆 | 查询与展示偏好 | 跨场景输出和工具偏好 |
| 知识记忆 | 账单事实与实体关系 | 工作流、案例和模板 |
| 高效检索 | 语义召回与金额聚合 | 新会话主动召回 |
| 安全遗忘 | 按月份精准删除 | 墓碑防复活 |
| 记忆流转 | OCR 进入长期知识 | 工具结果沉淀与复用 |
