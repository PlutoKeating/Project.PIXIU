
银河麒麟 V11 原生探针验证了产品写入、向量检索、向量删除、自然语言遗忘和删除后不可见。能力接口显示两个 SDK 均实际使用麒麟实现，符合该包的严格配置。

## 量化评测

数据集 `pixiu-family-expense-v1` 由团队依据赛题附录 A 构建，包含 50 组家庭支出检索、15 组偏好和 25 组冲突用例。检索用例重复运行形成 1000 个延迟样本。

### Debian 兼容环境的历史结果

| 指标 | 结果 | 赛题阈值 |
|------|-----:|---------:|
| 知识检索召回率 | 100% | ≥85% |
| 偏好提取准确率 | 100%（15/15） | ≥85% |
| 冲突处理正确率 | 96%（24/25） | ≥88% |
| 检索 P95 延迟 | 115 ms | ≤500 ms |

这些数值用于检查算法和工程改动，运行配置为 Debian portable。V11 原生测试应使用同版安装包，另行记录数据集、样本量和结果。

## 已实现功能与待验证范围

| 能力 | 实现内容 |
|------|----------|
| 多源接入 | 对话、工具结果、用户行为、配置、OCR 结构化文本；单包未包含图片 OCR 扩展 |
| 偏好记忆 | 支持三类偏好提取、置信度、版本历史与回溯 |
| 知识记忆 | 支持事实、工作流、案例、模板与来源关联 |
| 混合检索 | BM25、向量与关系图并行召回并进行 RRF 融合 |
| 冲突处理 | 支持 NEW_WINS、MERGE、MANUAL 与完整审计 |
| 精准遗忘 | 预览后人工确认、知识不可见、向量删除和共享删除记录；原始证据和关系仍保留 |
| 记忆流转 | 支持短期、中期、长期记忆的保存、召回和晋升 |
| 多设备同步 | 支持配对、签名、mTLS、Gossip、反熵与 CRDT 收敛 |

## 安全与失败测试

安全测试检查敏感信息及使用范围、重复请求的恢复授权、服务迁移、安装签名和升级恢复。敏感检测出错时应拒绝写入；设备重放旧记录后，已遗忘内容应继续保持隐藏。

## 供应链验证

安装包包含固定版本的 KylinAgent 宿主、58 个哈希锁定 Runtime wheels、PIXIU Provider、双 SDK 原生扩展、SBOM、NOTICE、对应源码与构建记录。

历史包的来源和依赖审查结果为 `status=pass`、`ready=true`。新候选需要重新构建和检查，并用 SHA-256 关联桌面程序、源码、构建日志、依赖目录、锁文件及离线安装日志。
