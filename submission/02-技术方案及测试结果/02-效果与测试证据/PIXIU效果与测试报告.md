# PIXIU 效果与测试报告

## 测试目标

测试围绕赛题七项功能、银河麒麟 V11、指定 Embedding 与 Vector Engine SDK、OS Agent 记忆闭环、端侧性能和分布式同步展开。所有自动化结果均绑定代码版本、运行画像和原始记录。

## 测试分层

| 层级 | 验证内容 | 证据形式 |
|------|----------|----------|
| 单元与契约 | 数据模型、API、算法、Provider、发布工具 | pytest、CTest |
| 集成 | 写入、检索、偏好、冲突、遗忘、同步 | JSON 报告 |
| 平台 | V11、双 SDK、用户服务、安装包 | 原生探针、系统记录 |
| 效果 | 召回率、偏好准确率、冲突正确率、延迟 | 逐样本结果、汇总报告 |
| 场景 | Agent 生命周期、三设备、安装升级 | 去敏操作记录、截图、视频 |

## 自动化回归

当前代码基线完成前端 38 项 CTest，以及后端与 Module E 809 项 pytest。测试覆盖记忆写入、三通道检索、偏好版本、冲突仲裁、精准遗忘、同步协议、Agent 适配、版本治理、签名校验和升级恢复。

## V11 与双 SDK 验证

审阅包 `pixiu_0.1.7-1_amd64.deb` 的 SHA-256 为：

```text
cf95e13ae406ffe393f6efbdb6944f2518701c675b64a409fb3b3289e1f99e8a
```

银河麒麟 V11 原生探针验证了产品写入、向量检索、向量删除、自然语言遗忘和删除后不可见。能力端点返回 Embedding 与 Vector Engine 均使用 `kylin` runtime，并满足 strict 画像要求。

探针直接执行 Vector Engine 的连接、数据库加载、集合创建、写入、搜索、删除、集合清理和断开；产品 API 另行验证端到端写入、召回与遗忘，避免只验证 SDK demo。

## 量化评测

数据集 `pixiu-family-expense-v1` 由团队依据赛题附录 A 构建，包含 50 组家庭支出检索、15 组偏好和 25 组冲突用例。检索用例重复运行形成 1000 个延迟样本。

### Debian 兼容画像基线

| 指标 | 结果 | 赛题阈值 |
|------|-----:|---------:|
| 知识检索召回率 | 100% | ≥85% |
| 偏好提取准确率 | 100%（15/15） | ≥85% |
| 冲突处理正确率 | 96%（24/25） | ≥88% |
| 检索 P95 延迟 | 115 ms | ≤500 ms |

该表用于算法与工程回归，运行画像为 Debian portable。V11 原生 SDK 结果由独立原生报告保存，两类画像不混合统计。

## 核心功能结果

| 能力 | 验证结论 |
|------|----------|
| 多源接入 | 支持对话、工具结果、用户行为、手动配置与 OCR |
| 偏好记忆 | 支持三类偏好提取、置信度、版本历史与回溯 |
| 知识记忆 | 支持事实、工作流、案例、模板与来源关联 |
| 混合检索 | BM25、向量与关系图并行召回并进行 RRF 融合 |
| 冲突处理 | 支持 NEW_WINS、MERGE、MANUAL 与完整审计 |
| 精准遗忘 | 两阶段确认、级联清理、共享墓碑与防复活 |
| 记忆流转 | 支持短期、中期、长期记忆的保存、召回和晋升 |
| 多设备同步 | 支持配对、签名、mTLS、Gossip、反熵与 CRDT 收敛 |

## 安全与失败测试

测试覆盖敏感内容禁止进入共享域、敏感检测异常时失败关闭、作用域隔离、幂等恢复授权、未知 Agent unit 拒绝迁移、无效签名拒绝安装、升级健康失败自动恢复和删除墓碑防复活。

## 供应链验证

安装包包含固定版本的 KylinAgent 宿主、58 个哈希锁定 Runtime wheels、PIXIU Provider、双 SDK 原生扩展、SBOM、NOTICE、对应源码与构建记录。

供应链审计报告为 `status=pass`、`ready=true`。宿主产物、源码、构建日志、Runtime wheelhouse、锁文件和离线安装日志均以 SHA-256 互相绑定。
