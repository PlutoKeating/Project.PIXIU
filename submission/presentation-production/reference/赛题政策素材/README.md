# 赛题政策素材

本文件夹用于保存“OS Agent 记忆优化及高效应用研究”赛题汇报可引用的官方政策材料。

生成日期：2026-09-15

## 目录说明

- `原始网页/`：三个官方发布页面的原始 HTML 存档。
- `截图/`：三个官方页面的首页截图，截图可看到中国政府网、国家互联网信息办公室等官方站点标识及发文机关。
- `摘录/`：与赛题直接相关的原文摘录，以及政策来源对照表。

## 政策清单

1. 《国务院关于深入实施“人工智能+”行动的意见》（国发〔2025〕11号）
2. 《生成式人工智能服务管理暂行办法》（国家互联网信息办公室等七部门令第15号）
3. 《数字中国建设整体布局规划》（中共中央、国务院印发）

所有政策均不早于 2023 年，信息来源为政府官方网站。
