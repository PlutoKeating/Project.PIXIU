# 路演修订结构

目标：评委仅阅读 PPT 也能理解背景、定位、功能、实现、完整案例和商业设想。

1. 封面：PIXIU·貔貅，面向麒麟 OS Agent 的去中心化记忆系统。
2. 目录：背景需求 → 方案架构 → 功能亮点 → 技术实现 → 完整案例 → 商业探索 → slogan。
3–4. 真实需求：多源资料、跨会话失联、跨设备断层、更新与控制；场景为设计推演，不伪称用户调研。
5–6. 服务定位与总架构：用户桌面、上游 Agent、原创 Provider、记忆引擎、基础设施、系统双 SDK 与可信设备。
7–12. 功能亮点：价值循环、自动积累、审批更正、追溯检索、偏好版本、多设备协作。
13–22. 完整技术：接入、检索、知识组织、偏好、生命周期、两类冲突、同步、隐私遗忘、Agent 时序、部署。
23–24. 证据：历史 portable 四项数值与阈值、0.1.12 原生实测、清晰限制。
25–28. 完整案例：社区活动组织者，授权目录、新会话查回与来源、更正审批、再次回读；前后价值对照。使用同一次真实 V11 实录的公开合成活动资料。
29–30. 商业探索：候选客户、付费事项、交付与维护成本、试点验证流程。不虚构营收、份额或效率提升比例。
31. 一句话收束。

视觉：蓝白系统主题，渐变底、网状连线与粒子、层叠描边、圆环/流程/时序/关系图；实际截图保持原始像素，不重绘产品界面。图示与实拍区分。正文按密度使用14–20pt，标题29pt，封面与结束语43–44pt，截图说明11pt；页脚9pt。
